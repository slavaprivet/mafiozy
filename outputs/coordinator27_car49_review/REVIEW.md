# Car49: проверка сохранённых измерений

Проверены байты production48 (486 pins), baseline48 (497), candidate49 (513), шесть RUN/RESULT, три PAIR и сохранённые fixtures. Полные хеши доказательств, исходные состояния и пересчитанная статистика находятся в REVIEW.json. Движки не запускались; файлы владельца не изменены.

Каждая сторона содержит 721–722 реальных интервала отрисовки за ~5 секунд; интервалов свыше 16.667 мс нет. Настройки, фиксированная камера, три ID NPC, Palazzo, стартовые и конечные fingerprints совпадают внутри пар. Движение использует настоящие E/W/Space; конечные позиции машин различаются на 1.18–1.52 см.

Парковочная пара сохраняет MATCHED_MEASUREMENT. У moving02/03 исходный UNVERIFIED остаётся: билеты 159/161 и 173/176 не соседние. При этом каждый сохранённый запуск имеет отдельный exclusive perf lease и clean audit. Разрыв номеров сам по себе не доказывает перекрытие нагрузки; повтор только ради номеров не нужен. Данные движения допустимы как явно ограниченная диагностическая оценка, без переименования авторского verdict.

Полная performance acceptance и production **не подтверждены**. NPC poses/общий simulation epoch и process RSS не записаны. Static allocation — не RSS. Во всех этих окнах дым неактивен; стоимость активного дыма, критического мотора и проколов ими не закрыта. Moving49 заканчивает с одним native-collision damage event и HP двигателя 97.620891, поэтому описание «без урона» нельзя понимать буквально. Startup/cache/boarding вне измерения; камера тестовая фиксированная.

Wall frame_ms авторитетен для времени кадра. Cached process/physics monitor maxima не являются независимыми затратами каждого кадра; отрицательная дельта p95 не доказывает оптимизацию. Root может использовать эти измерения для решения о стоимости +25–26 MiB static и +42–43 draw calls, отдельно закрывая реально недостающие сценарии.
