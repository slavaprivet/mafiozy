# Минимальный новый модульный дом для Root24

Весь frozen пакет независим от меняющихся expansion-файлов. Сохранить относительные
пути runtime preload closure. Полное содержание сверять по RECEIPT.json.

Здание: REBUILD-VISUAL-hillstep_chalet_v1-002, прежний assetId hillstep_chalet_v1.
Новый корпус: 29 реальных замкнутых модулей, 348 треугольников, 4 поверхности,
один MeshInstance, бинарник16,303байта. Native position примерно
(-351.13449,0.015,79.95), rotation Y90°. Точный сохранённый frame и source pins
в expansion/modular_buildings/export/minimal_entrypoint.json.

1. Loader.instantiate_prefab(prefab_path, expected_sha256). Бинарник уже построен;
   не запускать Builder или Panels census в live blast path. Добавить instance
   в согласованный source owner, сохранить его native transform.
2. Loader.bind_record(instance, original_record, true) только после реального
   owner approval замены: default false. Полученные record.component_profiles
   и modular_geometry_provenance сохранять. Body path modular_body_v1.
3. Runtime из expansion/compound_node/compound_runtime.gd сохраняет прежний
   configure/register_building/apply_explosion/reset_building/stats/dispose.
   При register передать visual_root=instance и только действительно принадлежащие
   этому source_id original collider roots; никаких чужих interior_kind тел.
4. При фактическом включении заменить соответствующий прежний внешний корпус
   и его collision authority, сохранив gameplay ID/ownership/anchors/site/NPC.
   Не накладывать новый дом на старую неотключённую стену. Реальные owner anchors,
   стекло и интерьер остаются отдельной Root интеграцией, не autogenerated-ready.
5. Cold load/admission заранее при загрузке: финальный prefab load4.865ms,
   binding.584ms, admission35.047ms, whole registration36.918ms в изолированном
   тесте. Это НЕ FPS и не операция в момент RPG.

Проверено: все78 новых геометрий PASS76005, исходные pins; binary export/load1399;
минимальный prefab → private Runtime register/reset/dispose PASS22. Новый двухэтажный
дом в этом же host: четыре admitted receipts160, физический пролом и standing
capsule1.7м, соседняя стена, replay/reset, pending material mutations PASS39.
Контакт под45° uses real current triangle nearest point; AABB только broadphase.
В compound node нет externally mutable glass/door ownership: отдельные nodes.

**Пределы:** это локальные проломы, не обрушение всего дома. Structural support
propagation пока отсутствует. Этот конкретный prefab ещё не обстрелян настоящим
player/native weapon; Root должен сохранить real aim/RPG/ammo/W/collision evidence
и comparable loaded frame-time/memory. Стекольный first-material hitch этим
пакетом не исправлен. Не включать все78 сразу без полной приёмки.
