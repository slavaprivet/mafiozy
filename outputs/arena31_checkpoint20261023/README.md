# Полигон31: сохранённая работа

Рабочий срез в main. Состав и пройденные/оставшиеся проверки — CHECKPOINT.json и qa/EVIDENCE.json; это не полная приёмка боя100NPC. Game содержит обычные файлы, без ссылок на D. Запуск: launch.ps1. Production current_version не переключён.

F10 — камзол; F11 — броня героя; F4 — броня мишени; F6 — новая мишень; F5 — сброс героя/сцены. После ранения смена одежды блокируется до F5, чтобы не восстанавливать отрезанные части.

Лук: удерживать ПКМ для натяжения, затем нажать ЛКМ для выстрела. Ранний щелчок не выпускает стрелу; отпускание ПКМ отменяет натяжение. Проверка настоящего попадания после исправления прицела прошла. Броня и отделение частей со стрелами требуют оставшихся сценариев.

Обязательная очередь ошибок/регрессий записана в qa/TODO.md. Последующие успешные прогоны должны обновлять статус, а не удалять ранее неудачные результаты.
