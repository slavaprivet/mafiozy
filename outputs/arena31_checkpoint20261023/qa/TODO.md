# Обязательная проверка сохранённой работы

Статус: не завершена. Внешний dsh_gate_collision_probe сохранён по прямому ответу пользователя; запускать проверки штатным scheduler после освобождения. Не считать истечение очереди успешным прогоном.

- [ ] Компиляция текущих G/E и поверхности раны; нулевой stderr.
- [ ] Копьё: 600 кадров удержания, только осевой выход, никаких самопроизвольных выдёргиваний.
- [ ] G/E: меч и копьё на живой и мёртвой цели; тот же экземпляр/рана, корректная масса и коллизия трупа.
- [ ] ПКМ+ЛКМ копья: сначала извлечение, прицел/бросок только после выхода.
- [ ] Лук: настоящий ввод натяжения/отмены/выстрела, полёт, попадание, закрепление стрелы, глубина и броня.
- [ ] Герой: ранения голого торса/камзола, кровь, отсечение, детали и три вида брони.
- [ ] Щит с новым торсом/камзолом: ПКМ, повороты, хват и отсутствие самопроникновения.
- [ ] Q/G/Q/E для всех семи видов оружия после объединения.
- [ ] Сравнение кадров30/31, отдельный срез и100фоновых геометрических работ; не выдавать за бой100AI.
- [ ] Финальные source pins, проверка ошибок логов, сохранение последующих исправлений в main, открытие сцены.

Пример из каталога qa: `python run.py menu_final optimization31/menu.gd --graphical`. Для профиля вместо --graphical использовать --perf. Фикстуры принимают --qa-out/--lab-out от runner. Вывод хранится в игнорируемом results/.
