# Полигон32 — проверяемые этапы

Первый этап: повреждения опорных конечностей игрока, поверх точного опубликованного полигона31 (d7af2e98).

Одна нога: сохранено ограничение скорости до24%, вместо двухногой походки — физические короткие подскоки; Space даёт ограниченный прыжок только с опоры. При потере руки скорость88%, торс наклонён к отсутствующей руке на8°, верхняя коллизия следует позе. Исходная коллизия целого игрока сохранена.

Приёмка:44 проверки в графическом Godot, реальные MeshSever через приёмник удара, затем InputEvents ходьбы/прыжка и реальные столкновения со стеной; source stable, stderr0. Это не имитация естественного удара противника. Проверены обе стороны, запрет ходьбы/прыжка без обеих ног и F5 reset. Первые неудачные проверки сохранены.

Запуск: PowerShell launch.ps1 из этой папки (или Godot --path game res://scenes/arena27.tscn). В первом промежуточном этапе заголовок сцены ещё31. Общая сцена замка и её current_version не переключены. Топорики и новые струи крови пока готовятся отдельно и в этот этап не входят. Физическое оседание после потери обеих ног — следующая проверка; полный FPS50на50 не принят.
