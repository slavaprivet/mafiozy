# Полигон32 — проверяемые этапы

Этап3: движение после ранений и усиленное кровотечение поверх опубликованного полигона31.

Одна нога: скорость24%, физические короткие подскоки, ограниченный Space только с опоры. Потеря руки: скорость88%, наклон8° к отсутствующей руке, верхняя коллизия следует позе. Исходная коллизия целого игрока сохранена.

Крупные принятые раны и срезы дают непрерывный поток крови, малые — капли. Источник следует реальному месту раны; уже вылетевшая кровь движется в мире. Для новой системы выделен общий пул256 элементов/24 источника, максимум4 источника на персонажа. Это визуальный эффект; прежние правила HP не изменены. Старые капли имеют отдельный лимит384. Проверены сбросы, смена меша, истечение времени отрезанных частей и насыщение пула.

Совместная приёмка:16 проверок в графическом Godot и44 проверки ранений/движения с неизменными исходниками, stderr0. Дополнительно сохранены отдельные18 проверок пула,7 проверок фактической поверхности раны и первоначальные неудачные результаты. Срезы вызываются через настоящий приёмник удара/MeshSever, после чего подаются игровые InputEvents; это не приёмка естественных ударов NPC во всех сценариях.

Запуск: PowerShell launch.ps1 из этой папки (или Godot --path game res://scenes/arena27.tscn). Общая сцена замка и current_version не переключены. Топорики проходят следующую проверку. Полный FPS50на50 не принят.

При потере обеих ног опора определяется по оставшейся видимой геометрии, тело опускается обычной гравитацией. Подготовка сеток и обработка вершин распределены по кадрам. В отдельном графическом прогоне пик подготовки снизился с9,4–10,3 до5,2–5,5мс; это не общийFPS. На объединённой сборке отдельно повторены30 графических проверок оседания и44 проверки ранений.
