**One small defensive API regression:** `rpg_effects.gd:77` assigns `shot.projectiles[0]` to a typed Dictionary without first checking the element type. An array of size1 containing null/int/Object raises a runtime type error instead of returning a rejection; the previous path let Flight validate the Variant safely. Normal Fire always supplies a Dictionary, so the strict ordinary-input run is unaffected. Recommended exact addition to the preceding check: `or not shot.projectiles[0] is Dictionary`. Also rejecting nonfinite `receipt.origin` before vector rotation avoids needless invalid-vector operations; Flight currently still rejects the resulting direction, so that is defensive validation rather than an admitted bad launch.
