# Проверка прерывания покупки58

Подготовлен отдельный маленький harness без копии игры. Движок ещё не запускался; ожидается сообщение root об освобождении тестового окна. Python проверен на синтаксис, read-only dry-run подтвердил все1135 источников stage58_02 и engine/scheduler pins. GDScript пока не проверен native parser.

`run58.py` по умолчанию только проверяет подготовку. Для запуска нужен `--go`; поддержаны `--case shop|restaurant` и один из десяти исходных жителей. Проект жёстко задан `coordinator31_npc57/game`, SHA CANDIDATE58 stage02 `4a00c3c85b4d705ce917c60a7d0b92deb634d24eb57b41cff2664d24e2cfb70e`. Флаги обычной57 сохранены, поведение/seed/кошелёк/энергия глобально не переопределяются.

Единственное исправление ввода: наружный промах вниз под достижимым углом; фактические лучи камеры и muzzle не должны попадать в жителя или сотрудника. LMB подаётся после пяти стабильных кадров, только пока житель действительно обслуживается и ещё не оплатил покупку. Записываются actual/requested pitch, текущие пределы камеры, состояние RMB, лучи и точный момент LMB. Камера и NPC напрямую не поворачиваются/перемещаются. Одно прежнее QA размещение только игрока на проверенном физическом полу сохранено.

Все прежние проверки сохранены: полное HP, настоящий вход и сотрудник, точный native near-shot, физический выход и освобождение claims, сохранение неоплаченной покупки, паника+10%,15сек тишины, одна настоящая оплата, восстановление энергии, полный повторный выход, следующая прогулка, движение остальных девяти и неизменность состава10+12. Дополнительно требуется ровно один настоящий промах и отправка выстрела в неоплаченном service window.

Runner сохраняет full SOURCE до/после, CONTROL_PINS до/после, HARNESS до/после и точный архив. Native child использует headless read lease,310сек watchdog,64МиБ cap вывода и минимум128МиБ остатка диска; закрывает только своего ребёнка. Пользовательская игра, F5, frozen57 и shop01/shop02 не изменены.

`READY_FOR_REVIEW58.json` содержит pins и готовую команду первого запуска. PASS этой будущей проверки дополнит приёмку услуг, но не заменит ordinary soak или отдельный FPS замер.
