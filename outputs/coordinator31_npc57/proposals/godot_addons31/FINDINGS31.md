# Готовые средства Godot: проверка 15 октября 2026

StateCharts прошёл отдельный запуск на нашем Godot 4.7.2. Его можно использовать при следующем локальном упорядочивании переходов NPC: библиотека уже предоставляет проверки условий, отменяемые задержки и события входа/выхода. Сейчас в город не внедрён. Переписывать всю логику жителей ради диагностического окна не предлагается.

| Средство | Проверено | Практическое применение | Ограничение |
|---|---|---|---|
| Godot StateCharts 0.22.5 | Исходники; настоящий импорт и запуск 10 диаграмм, 9/9 условий PASS | Явные переходы Opening → Crossing / Recover; отмена ожидания при угрозе; журнал состояний; готовые средства просмотра диаграмм | Для существующих NPC нужны реальные события и условия. Библиотека сама не проверяет коллизии, не освобождает дверь и не диагностирует произвольные поля старого скрипта |
| LimboAI | Исходники и заявленная совместимость; native запуск не выполнен | Деревья поведения, иерархические состояния, blackboard, просмотр выполняемого дерева, собственные счётчики производительности | Просмотр относится к поведениям, представленным деревом LimboAI. Нужны GDExtension/модуль и переход соответствующего поведения на его API; выгода для нашего FPS не измерена |
| Встроенный профайлер Godot | Отдельный участок root `native_profiler31` | Первый инструмент для выяснения фактической стоимости нынешних скриптов без смены AI-фреймворка | Этот пакет не дублирует и не принимает результаты профилирования root |

В upstream StateCharts документированы guards, задержки, редакторская проверка и встроенный просмотр активных состояний. В практическом тесте проверены именно переходы и доступные сигналы; графический debugger не открывался. [Исходники StateCharts](https://github.com/derkork/godot-statecharts/tree/76d226a3efac66a72aea825382b320c94808f409).

Upstream LimboAI описывает C++ реализацию, GDExtension, визуальный debugger дерева и performance monitors. Таблица совместимости указывает для ветки 1.8.x GDExtension Godot 4.6+ и модуль Godot 4.7; это заявление проекта, а не наша проверка готового бинарника на 4.7.2. [Исходники LimboAI](https://github.com/limbonaut/limboai/tree/df8933d3e1a0e7884efb640c0e363140741c50cb).

## Настоящий небольшой тест StateCharts

`runs/native02/RUN.json` и `runs/native02/NATIVE.json`: импорт и native выполнение exit 0, stderr 0, источник и управляющие указатели без изменений. Движок сообщил `4.7.2-stable (official)`. Зафиксировано 28 событий десяти отдельных диаграмм.

- Все десять начинают в Opening.
- Закрытая дверь и отдельно занятая внутренняя точка запрещают переход.
- Пять переходят в Crossing только после обоих условий и затем в Ordinary.
- Трое немедленно уходят в Threat; старый таймер ожидания отменён, после quiet они переходят в Ordinary.
- Двое с неисполненными условиями получают Recover по заданному пределу ожидания.

Условия двери в тесте синтетические, физической сцены/кассы/жителей города здесь нет. Пределы 0.15 и 0.08 секунды выбраны для короткого теста библиотеки и не предлагаются как игровые значения. PASS не подтверждает исправление зависания магазина и не подтверждает ускорение игры.

Две native операции идут через актуальный scheduler: импорт с write lease на собственный маленький project, выполнение с read lease на тот же project; дочерний watchdog 30 секунд. Пользовательская игра, release57, F5 не изменялись. Начальная попытка `native01` остановилась в Python до запуска движка из-за отсутствующего необязательного `.vscode/launch.json`; сохранена отдельно. Исправлена только проверка наличия файла в новом runner.

## Происхождение и размер

`UPSTREAM31.json` содержит commit, путь, размер и SHA256 каждого скачанного файла. После native прогона все upstream SHA256 совпали. StateCharts: commit `76d226a3efac66a72aea825382b320c94808f409`, 96 файлов / 159026 байт; LimboAI: commit `df8933d3e1a0e7884efb640c0e363140741c50cb`, 4 файла / 14955 байт. Скачаны только исходники, описания и лицензии; без демо, C# обёрток и бинарников. Состояние репозиториев закреплено конкретными commit; это не обещание поддержки будущих версий.

Оба исходных проекта используют MIT; копии лицензий сохранены. Для арта/логотипа LimboAI в его README указан отдельный CC BY 4.0, такие материалы не скачивались и не используются.

Рекомендация: оставить текущую работу над физическим проходом и очередью в своём небольшом исправлении; использовать встроенный профайлер для текущего кода. StateCharts оставить проверенным кандидатом для одного будущего участка состояний с отдельной приёмкой. LimboAI сейчас ограничить исследованием: миграция поведения и загрузка native зависимости не оправданы исправлением одного прохода.
