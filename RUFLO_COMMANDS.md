# Ruflo — шпаргалка для проекта Мафиози

## Установка (один раз)
Запусти `install_ruflo.bat` двойным кликом.

## Как использовать в Claude Code

Открываешь Claude Code в папке Мафиози, и пишешь:

### Разработка нового фичера
```
/sparc "Добавить систему ограблений банка в world.html"
```
Ruflo сам разобьёт задачу на фазы: спека → архитектура → реализация → тесты.

### Параллельная работа нескольких агентов
```
/swarm "Исправить баги в battle.html и обновить HP-бар как в demo_isometric"
```

### Сохранить идею в памяти (между сессиями)
```
/memory store "Хочу добавить дроп-систему: убитые NPC роняют деньги"
```

### Найти что-то из прошлых сессий
```
/memory search "дроп деньги NPC"
```

### Сгенерировать тесты для бота
```
/testgen mafiozi_bot.py
```

### Аудит безопасности
```
/security-audit
```

## Типичные задачи для этого проекта

| Задача | Команда |
|--------|---------|
| Новая механика в world.html | `/sparc "описание"` |
| Баг в bot.py | `/fix "описание бага"` |
| Оптимизация рендера | `/swarm "оптимизировать Canvas рендер тайлов"` |
| Документация кода | `/docs world.html` |
| Проверка перед деплоем | `/security-audit` затем `python github_upload_world.py` |

## Структура памяти Ruflo

Ruflo хранит контекст в `.claude-flow/memory/` — туда попадают:
- Успешные паттерны решения задач
- Архитектурные решения
- История изменений по файлам

Это помогает Claude Code "помнить" что делали в прошлых сессиях.
