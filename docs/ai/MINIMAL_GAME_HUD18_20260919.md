# Минимальный игровой HUD — 19 сентября, Координатор18

Готов исходный узкий пакет по просьбе пользователя убрать лишние постоянные надписи и кнопки. LIVE не выполнялся: единственная игра у координатора.

## Изменения

- `assets/maps/city_rebuild_v1/mercenary_command_ui.mjs`: постоянная кнопка «Отряд и приказы» удалена. Карточки бойцов `openMember` / общий `open` сохраняют найм, оружие, навыки, увольнение. «Следовать за мной» доступна только внутри явно открытого управления, не на закрытом игровом HUD. V продолжает отдавать реальную команду. Внешние уведомления приказов — один повторно используемый toast на 2.5 секунды; новый приказ обновляет срок, обычный update его не продлевает. Dispose отменяет таймер.
- `assets/maps/city_rebuild_v1/walk_debug_panels.mjs`: нет кнопки «Проверка». В локальной QA игре **Ctrl+Shift+F9** раскрывает и скрывает прежние диагностические панели; набор объектов и URL-флаги сохранены. Ввод текста и key repeat не переключают QA. Установлен постоянный точный CSS для `#districtRepHud` и пустого `#drive-status`, включая обычную не-QA walk игру. Source районов/репутация не менялись.
- `assets/maps/city_rebuild_v1/walk_preview.mjs`: только idle fallback «Подойди к нужной двери машины» заменён пустой строкой. Реальные подсказки E у доступной двери, посадка/выход и движение в машине сохранены.

Карта, оружие, личное дело, собственные бейджи, таймеры целей и сообщения о госпитализации не изменялись.

## Проверка

12/12 тестов `test_mercenary_command_ui.mjs` + `test_walk_debug_panels.mjs` PASS. Проверены клавиши V/Escape, доступность карточек и изменения экипировки, pending-дубли, toast до и после 2.5 секунд и продление только новым приказом, доступ QA только локально и снятие слушателей. Синтаксис трёх production модулей PASS.

Новых геометрий, render pass, per-frame DOM обходов нет; одна CSS таблица, один keydown listener и максимум один timeout на уведомление. Производительность общей сцены не проверена. Координатору: после загрузки проверить чистый HUD; для подготовки площадки использовать Ctrl+Shift+F9, затем убрать тем же сочетанием.

- `#onlineTag` и `#errorBanner` скрыты на основном walk HUD; сетевые события/обработка ошибок не менялись.

Тёмная зелёно-коричневая панель, тонкая латунь, светлый текст; фиолетовая рамка и нижняя позиция убраны. События, срок и закрытие world toast сохранены. ## Последнее решение пользователя — приказы над миникартой

**Заменяет top38%:** command toast V/X теперь стоит над миникартой, в той же области, что world witness toast. Если world toast виден, команда поднимается над ним с зазором12px. Высота world toast измеряется одним ResizeObserver только при изменении его размера: длинные сообщения не перекрывают приказ. Учитывается адаптивный порог700px, ширина230/190px. Срок2.5с сохранён. Новых постоянных кнопок нет. 12/12 UI/QA тестов и синтаксис двух модулей PASS; расположение требует LIVE проверки координатором.
