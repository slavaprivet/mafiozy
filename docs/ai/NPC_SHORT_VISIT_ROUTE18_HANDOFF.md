26 из 108 физических стартов больше не требуют A* (4 больница, 8 типография, 14 дом). Сокращение native queries примерно 3%, 10%, 20%; это устойчивее wall-clock CPU измерений при общей машине. В одном повторе типография показала CPU 337→370 мс, поэтому гарантированного процента ускорения всей сцены не заявляем. Очередь в этом узком benchmark не симулируется — измеряются принятые 4 ms срезы планировщика. Атомарная collision query может пересечь deadline, как и в прежнем A*.
