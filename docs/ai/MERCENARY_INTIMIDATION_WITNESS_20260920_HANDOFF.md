## Поведение

Успешное действие громилы теперь вызывает actual source `_npcApplyIntimidation`: отменяет ещё не отправленный вызов, снимает телефон/замирание/укрывание и запускает обычное физическое бегство от специалиста. По последнему прямому уточнению пользователя страх длится ровно 60 секунд после успешного запугивания. Выстрелы, новые преступления и чтение состояния НЕ продлевают срок. Внутри этой минуты опасность вызывает бегство без звонка, затем возвращается обычное поведение свидетеля. Новое успешное запугивание может начать новую минуту.

Guard подключён к markNpcSnitch, witness queue/retreat/finish, direct snitch report, typed suspicion report и прямому `_npcActionCrime` меню угроз. `_npcBeginPanic` для запуганного выбирает flee. Обычные NPC сохраняют прежнюю очередь, задержку звонка, шансы и лимиты. Уже зарегистрированное сообщение не удаляется. Для отправленного `civilian_report`, ещё ожидающего ACK, сохраняется nonce и поздний подтверждённый сервером отчёт правильно передаётся полиции; новые попытки от этого NPC подавляются.

Source `getTarget` и world NPC view экспортируют **fearActive:boolean** и **fearExpiresAt:epoch ms**. При смерти/истечении false/0. Эти поля переданы safe_operator_clearance18 для компактного обозначения страха. Private `_intimidatedUntil` остаётся performance.now() clock, UI его не читает.

Запрос касается именно свидетеля. Прямое наблюдение преступления полицейским и уже зарегистрированные серверные npc_robbery/полицейские инциденты не отменяются. Телефон скорой в момент запугивания прекращается как прерванное действие, но существующие подтверждённые EMS/полицейские записи не удаляются.
