## Настоящие два РПГ в изолированном квартале

В соответствии с правилом проекта «остальным headless, GPU через root» Buildings2
выполнил последовательные headless прогоны inherited frozen23g проекта, без
второй графической игры и без изменения production main/player/project.
При начале headless-проверки существовала пользовательская24a PID31528;
Buildings2 её не закрывал. После завершения финальный inventory показал только
Manager45268: причина завершения24a не установлена, открытой игру не объявлять.

Headless02 доказал вырез buttress, но обнаружил два соседних каменных косяка:
`Far east display stone jamb_001` и `East display stone jamb`. Они также состоят
из78 geometric planes; фактическая толщина .235m, исходный Bright warm limestone.
Добавлены только три точных TEST_ONLY профиля под проверенный GLB hash, без
повышения мощности, переноса точки прицеливания или исключения соседних деталей.

Headless03 baseline + candidate и сравнение **PASS по поведению**:
`outputs/destruction_loaded_evidence_20260930/HEADLESS_COMPARISON03.json`.
Одинаковые SHA всех source trees/settings/capture/input schedule; два обычных
native RPG160, настоящий R reload/списание патронов/shot IDs/native terminals.
Первый толстый камень сохраняется, второй event completed4 parts/no failures;
7 rubble records, локальная коллизия исчезает. Все8 зданий и3 NPC сохранены,
HP/rig/collision IDs не изменились. `performance_pair_valid=false` намеренно.

Диагностика candidate03: max runtime phase2.542ms; после второго выстрела
исходная геометрия меняется через580.261ms, короткий локальный луч освобождается
через1047.022ms. Это наблюдаемая задержка, не обещание мгновенного разрушения.
Короткий луч не доказывает проход стоящего игрока через заднюю стену:
`planned_shell_mesh_replaced=false`. Исходную цель/прицеливание не менять,
следом проверять реальный пролом всей стенки и проход игрока.
