# Проверка интерфейса героя, 20 ноября 2026

Сверено с запросом о травмах, смерти, броне и оружии и с последним снимком экрана.

| Требование | Состояние |
| --- | --- |
| Реальное HP; отсечённая голова всегда даёт 0 HP | Проверено в `test_hero_vitals_integration.gd` и игровом пути смерти. |
| Травма части тела не исчезает самопроизвольно; сброс при новой жизни | Проверено для критической руки, отключённой руки и возрождения. |
| Кровотечение по ранам, процент, место, постепенная потеря HP | Проверено для одновременных ран и их прекращения. Обновление состояния идёт по событиям и активным ранам. |
| Горение вместе с кровотечением; без строки «Здоров» | Проверено в HUD и проверке огня через препятствие. |
| Лёгкая, средняя, тяжёлая броня на соответствующих частях схемы | Привязана к реальным слотам экипировки; смена идёт по сигналу. Отсечённые сегменты бронёй не закрываются. |
| Значок перед названием каждого оружия; «Без оружия» без предмета в руке | Все девять средневековых значков присутствуют; поднятие/сброс меча проверены. |
| Физическое падение, отключение управления, камера и причина смерти | Графический прогон с бронёй и отдельный тест боя/падения проходят. |
| Сплошной рисунок без чёрной точки на кисти | Геометрия суставов перекрыта. Источник точки — пустая панель подсказки меча, которая перекрывала кисть; теперь скрыта при пустом тексте и перенесена за пределы HUD. Сверены графические кадры без брони и с бронёй. |

**Остаётся вне реализации:** физическое разрубание корпуса героя пополам. В текущей боевой логике смертельный удар по груди/тазу убивает героя, но не делит его модель; поэтому схема не должна показывать разделение без реального mesh cut. Диагностическая проверка интерфейса для подтверждённого разреза существует, но это не проверка игрового разрубания.

Проверка FPS боя 50 на 50 в этом проходе не проводилась.
