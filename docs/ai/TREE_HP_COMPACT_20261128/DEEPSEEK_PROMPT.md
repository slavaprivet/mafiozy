# Краткое ревью компактного HP дерева

Godot 4.7.2. Один shared Label3D показывает `ДЕРЕВО current / max` и компактную
10-сегментную полосу. Второй shared Label3D на каждом принятом ударе показывает
красный `−N HP` на стабильной привязке дерева, за 0.92 с плавно поднимается
только на 0.24 м и исчезает; разные точки контакта не меняют экранную привязку.
Предыдущий Tween перед новым ударом kill, Label переиспользуется без аллокации.
Подсчёт примерных оставшихся ударов удалён. Подсказка подбора бревна использует
тот же общий UI, но только для owner `tree_log` уменьшается 14→12 px и клавиша
16→14 px. Автотесты 51/51 дерева и 14/14 модального инвентаря прошли.

Назови только критические риски такой реализации и обязательную проверку.
