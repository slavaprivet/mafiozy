# Действующая задача редактора карты — Godot

Прямое поручение пользователя 27 сентября 2026: закончить редактор карты
для Godot вместо прежней браузерной цели /walk.

## Критерии завершения

- K открывает/закрывает редактор, восстанавливая игровую камеру и управление.
- Вид сверху и свободный полёт с понятными русскими подсказками.
- Каталог всех исходных объектов: здания, памятники, дороги, земля, трава,
  фонари, знаки и остальные объекты карты.
- Выбор, добавление, перемещение, поворот, удаление ПКМ и undo/redo.
- Сохранение и повторная загрузка карты, импорт/экспорт для публикации.
- Сохранены модели, материалы, IDs, коллизии и игровые связи.
- Оптимизация без потери качества; живой прогон через владельца одной игры.

## Объекты — обязательная часть оптимизации (29 сентября)

Не считать ускорение редактора завершённым без проверки зданий, памятников,
фонарей, знаков, дорожного декора, машин и процедурных объектов. Сохранять
исходные mesh/material/texture/shadow/collision/ID и доступность действий;
ускорение не должно скрывать объекты, менять дальность их прорисовки или
отключать коллизии. Отдельно измерять (а) холодную загрузку каталога и сцены,
(б) переключение страниц/поиск и выбор объектов, (в) frame time p50/p95 и
draw calls живой сцены при одинаковой камере. Одни headless CPU-тесты не
заменяют (в).

Первые проверяемые резервы: убрать повторное построение временной панели на
9901 строк при входе, не пересканировать весь каталог при каждом переходе
между страницами, не пересоздавать одинаковые визуальные ресурсы, а дорогой
поиск кликом ускорять лишь после появления доверенного revision всех bounds.
Доступность/причины отказа не кэшировать как истину. При первом переносе всех
зданий сначала сверить 75 исходных ID и связанные collision/owner anchors;
текущие 8 объектов малого квартала не являются полным городом.

## Границы

Новые модули редактора готовить отдельно от main/player/project/export,
которыми с 29 сентября владеет Координатор22 (передача21). Согласовать
интеграцию и единственную GPU-проверку с ним. Старые PID43848/6508 не считать
живыми; свежий inventory22 при приёме был пуст. Текущий main остаётся только
фрагментом 31×31 / 8 исходных зданий из75. Headless-пакеты полного каталога
не создают отсутствующие в действующей сцене native owner связи.
Не перезаписывать NPC, транспорт, физику, traversal и navigation других авторов.
Готовность тестов не означает готовность редактора в пользовательской игре.
