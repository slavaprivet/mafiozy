# NPC seat entry — scoped patch20, 20 сентября 2026

Статус: **IMPLEMENTED / TESTED CPU**, не LOADED / OBSERVED / ACCEPTED.
Разрешение: Координатор20 передал явное согласование NPClead Художника19
на `npc_activity_pose.mjs` initial seat transition и actual-GLB regression.

## Дефект и исправление

Первая посадка инициализировала вес по `seat.since`, затем добавляла `dt`
предыдущего стоячего кадра. После 250 мс между кадрами новая посадка с
нулевым возрастом начиналась с веса 0.5. На настоящих male/female GLB
правая рука перескакивала на 0.243221 / 0.257330 м.

Изменены только две строки расчёта в `npc_activity_pose.mjs`, рядом
добавлен комментарий: первый наблюдаемый seat использует только age;
продолжающийся `lastSeat` по-прежнему получает `dt/.5`. После исправления
первая поза имеет вес 0 и перемещение руки 0. Наблюдение уже начатой
250 мс назад посадки имеет вес 0.5 вместо ошибочного 1.

AI, source elapsed, root, yaw, оружие, коллизии, props, транспорт и
`npc_actor.mjs` не изменены. Смена phase sit→rest не сбрасывает посадку.
Принудительная смена seat ID во время незавершённого предыдущего перехода
не расширялась: её отдельного подтверждённого repro в этой задаче нет.

## Лёгкий CPU A/B

Один и тот же rig, параметры и последовательность pose, чередование
before/after, прогрев исключён. Измеряется только `overlay.apply`, без
создания актёра, reset, renderer и GPU; Node v26.1.0.

| Сценарий | Выборки каждой версии | До p50 / p95, мс | После p50 / p95, мс |
|---|---:|---:|---:|
| Цикл вход→сидение→выход | 196 | 0.2060 / 0.3459 | 0.0036 / 0.2714 |
| Одинаковая полностью сидячая поза | 64 | 0.2133 / 0.2332 | 0.2131 / 0.2410 |

Медиана смешанного цикла меняется потому, что исправленный zero-age кадр
больше не запускает преждевременный IK. Это не общая оптимизация NPC.
На одинаковой полностью сидячей работе медианы практически равны;
малый замер p95 не доказывает общую производительность.

**Производительность общей сцены не проверена.** Браузер/GPU не открывался.
LIVE окно и наблюдение посадки/выхода в существующей игре согласует
Координатор20 с Художником19. Дополнительных draw calls патч не добавляет.
