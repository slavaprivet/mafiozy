# Запуск актуальной игры

На рабочем столе: **«Мафиози — актуальная версия»**.
Существующий ярлык **«Мафиози — последняя версия»** запускает ту же сборку.
F5 и «Запустить» для проекта `godot/mafiozi_walk` используют тот же запуск.

Текущая версия указана в заголовке окна и внутри игры. Если игра уже открыта,
второе окно не создаётся. Закройте игровое окно и снова откройте ярлык.

## Для следующего координатора

Единственный указатель принятой версии — `godot/current_version.json`.
После проверки следующей сборки обновлять его revision/assembly/hash/title,
а не ярлыки. Manifest и все его source pins проверяются перед каждым запуском.
Версия движка закреплена: Godot4.7.2. Непроверенные изменения frozen source
вызывают понятный отказ; незаметного возврата к старой сборке нет.

`tools/godot/launch_current_game.ps1 -CheckOnly -Quiet` проверяет файлы без
движка. Обычный запуск держит `Local\MafioziUnifiedPreviewLaunch` всю жизнь
игры, проверяет процессы и окна, сохраняет результат в `outputs/current_game`.
Сцена `current_version_launcher.tscn` завершает маленький процесс F5 перед
запуском настоящей игры. Для export template эта сцена открывает обычный main,
поэтому экспорт не зависит от локального PowerShell.

Интерактивная проверка сохраняет ранее запрошенные конечные50зарядов РПГ.
Это версия Палаццо/C4/стекла, не завершённая миграция всего города; dive39 и
исправления следов surface41 остаются отдельными кандидатами до проверки.
