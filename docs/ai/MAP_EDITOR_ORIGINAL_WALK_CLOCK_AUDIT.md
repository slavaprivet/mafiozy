## Approved next tools-only new contract

Coordinator21 permission relayed by root: one owner-managed gameplay clock for the **actual native melee practice** SourceMelee and Input. This is explicitly a NEW offline-editor contract, NOT original source parity. Melee subclass overrides virtual clock_ms; inherited _options and source configure callbacks naturally share it. Actual main subclass overrides only the factory seam `_install_preview_melee_practice`, preserving exact original physical-pose/owner setup and substituting that subclass before source configuration. No private source ports/timer/startAt/sequence rewrites or silent cancel. Source logic otherwise runs unchanged.

Clock is monotonic elapsed host time minus time spent in owner-issued pause intervals. Lease must belong to exact live main identity/generation and exact clock; duplicate/wrong/old-generation/orphan receipts reject without newer-owner rewind. Nested pause policy explicit (reject). Never reset external Time singleton, source clock, source timer queue or authority IDs. Pause SceneTree only in isolated actual-main diagnostic, verify original native physics tick frozen. After650ms pause actual300ms cooldown remains pending immediately afterresume, then drains naturally after remaining active elapsedtime. Repeated pause and failure/orphan/regeneration negatives required.

This bounded proof does NOT preserve all world clocks: NPC/navigation/water/focus/held input/ALWAYS UI/transport sessions remain HOLD. Main `_process` absolute water time is untouched. A complete editor pause cannot be accepted from this isolated clock proof.
