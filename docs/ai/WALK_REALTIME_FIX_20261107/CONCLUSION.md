# Исправление реального времени ходьбы — 7 ноября 2026

Жалоба сопоставлена с `scripts/main.gd`: обычный запуск без аргументов снижал
`Engine.max_physics_steps_per_frame` с Godot default 8 до 4. Комментарий исходной
оптимизации прямо допускал замедление игрового мира вместо просадки render FPS,
поэтому HUD мог продолжать показывать высокий FPS.

Исправление: обычная игра сохраняет значение 8. Явный диагностический аргумент
`--city-physics-catchup=N` для значений ниже 8 сохранён. Отдельный cap=1 действует
только во время загрузки города и затем восстанавливает исходное 8.

DeepSeek независимо рекомендовал тот же минимальный scope и отдельно отметил,
что окончательное подтверждение ощущения требует живого прогона: одного высокого
render FPS недостаточно, нужно сравнивать физическое время и wall clock.
