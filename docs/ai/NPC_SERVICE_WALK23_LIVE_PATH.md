# LIVE: существующая единственная игра, один printshop

Пакет после независимого ACCEPT перепривязан только к двум актуальным
комментариям shadow в Walk. World272a→9f5cc5a1; Walk8c10460d→337d53c2;
patch38d5b63a. Автор этот пакет не применял и игровую вкладку не открывал.

1. Координатор применяет exact manifest dependencies и World/Walk delta,
   затем обновляет **ту же**18538игру после завершения текущего GPU сценария.
   Не standalone preview, не новая вкладка. Для проверки использовать уже
   существующий видимый building QA интерфейс. Он включается `buildingqa=1`;
   если этого флага нет, добавить к URL текущей игры при согласованном reload.
   Проверить, что флаг передан в существующий Walk frame: появится панель ниже.
2. В видимом списке **«Здание для проверки комнаты»** выбрать
   `print_shop · REBUILD-VISUAL-print_shop-001`; нажать
   **«QA: к выбранной двери»**. Это существующая UI-команда безопасного подхода.
   Она требует героя пешком, без перехода/прыжка/падения/лестницы; при занятости
   сначала обычным способом выйти из автомобиля/закончить действие.
3. Одиночная E открывает общественную дверь. Войти обычным WASD; допустима
   видимая кнопка **«QA: пройти внутрь»**, использующая настоящий walking path.
   Служебная кладовка/касса находятся в этом реальном интерьере. Не двигать
   героя или source NPC через скрытые команды, не вызывать spawn/checkout вручную.
4. Сперва осмотреть живого продавца газет: полный корпус/руки/ноги, контакт с
   полом, касса/прилавок. При первоначальном приближении он мог уже закончить
   выход из кладовки, пока здание было вне камеры: это нормально.
5. Наблюдать за **естественным** покупателем: вход, подход к кассе, короткая
   остановка, обратный выход. Нет отдельной публичной кнопки создания покупателя.
   Если житель не пришёл в отведённое окно, фиксировать «естественный покупатель
   LIVE не наблюдался», не засчитывать CPU wallet receipt как увиденную сцену.
6. Существующим обычным игровым оружием проверить продавца как реального NPC:
   реакция на угрозу/полиция, урон, смерть. Ранение не считать подтверждённой
   смертью. Отсчёт60s начинается после actual death.
   После этого у мёртвого продавца нельзя купить; новая модель приходит из
   кладовки, открывает дверь, проходит, закрывает её и занимает рабочее место.
   Старый труп не превращается в нового работника. Оставлять свободным дверной
   проём; blocker задерживает выход/закрывание, а не продавливается NPC.
7. Отдельная попытка: смотреть прямо внутрь места появления в кладовке после
   смерти. Видимое место не должно породить нового NPC перед камерой. Отвести
   взгляд/выйти и проверить выход через дверь. Это может задержать replacement
   после60s; таймер не отменяет требования скрытого свободного места.
8. Если угроза возникает у покупателя возле кассы, он сразу получает своё
   panic/combat/report управление; покупка прекращается. После успокоения он
   физически выходит с фактической позиции. Не симулировать это присвоением HP,
   panicUntil, route или wallet через console. Обычное игровое событие и кадры.

Наблюдения камеры/движения обязательны; диагностический dataset сам по себе не
доказывает визуальный результат. Перед расширением на другие здания — одинаковые
камера/население/settings/прогрев до/после, p50/p95/draw calls/triangles. Сейчас
имеются только CPU actual source/GLB/foot/collision проверки и независимый ACCEPT.
