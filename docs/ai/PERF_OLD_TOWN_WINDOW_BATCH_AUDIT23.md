# Old Town window-frame batching audit — 23 September 2026

Base: `f4164be1a5a027a19daf99816967ee78f99261bb`.

All 22 `old_town_narrow_townhouse_v1` placements were reconstructed from the actual LOD0 GLB with the production door, residential-window, entry, storey and furnishing builders. Before batching they contain 1,408 potential main-pass objects and 1,298 shadow objects. The published general and generated-architecture batches reduce that asset-local census to 464 main and 375 shadow submissions on the `WEBGL_multi_draw` path.

The largest safe residue was generated by `applyResidentialWindows`: 22 opaque deep-recess pools and 66 opaque frame/interior pools, holding 4,004 immutable instances. They are static siblings of the breakable `ResidentialWindow_DeepGlass` pool. The broad hierarchy guard intentionally rejects every name containing `Window`, so these opaque pools remained outside the existing old-town architecture batches.

The candidate adds a narrow lane for those 88 source pools. Admission requires the exact old-town asset ID, LOD0, the pinned residential-window SHA, `InstancedMesh`, `worldBlastStaticBounds`, one of two exact mesh names, one of four exact opaque `MeshStandardMaterial` names, and a visible/effect-free/non-moving ancestry. Breakable glass, every door/hinge/handle, transparent material, wrong SHA/LOD/asset/material, hidden ancestry and moving ancestry fail open to their original rendering.

On the multi-draw path, four batches replace the 88 source pools / 4,004 instances. Potential submissions change from the published 464 main / 375 shadow to 380 / 291: 84 fewer main and 84 fewer shadow submissions (168 total). Together with the already-published old-town architecture batches, the general-batch baseline changes from 1,112 main / 1,002 shadow to 380 / 291.

Without `WEBGL_multi_draw`, authored `InstancedMesh` pools remain untouched: 1,282 main / 1,172 shadow submissions, six existing batches / 132 members, and zero old-town window-frame batches before and after this candidate.

Actual Three r180/GLB checks cover exact geometry and material ownership, root-local/world matrices, cast/receive-shadow flags, layers, source raycast, collision bodies, hierarchy visibility, detached-and-mutated fail-open behavior, isolated A/B, disposal/rebuild, strict negative admission cases and the fallback path. The combined lamp, garden, house, woodland, pavilion, window-integration, surface, culling and visibility suites pass. This is an asset-local CPU/object census; full-scene GPU/FPS and visual parity still require the single coordinated LIVE game tab after integration.
