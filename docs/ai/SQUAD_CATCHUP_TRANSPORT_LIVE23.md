## Приёмочные сценарии

1. Реальный отставший боец: до/после, recovery reason, сухая свободная точка,
   отсутствие пересечения здания/машины/бойцов, продолжение обычного следования.
2. Водитель и три свободных пассажирских места: физический подход/посадка,
   поездка, сохранение мест, выход через свои двери, безопасный пеший участок.
   Остальные бойцы не должны занимать уже занятые места.
3. Новое уточнение пользователя: X включает/выключает ответный огонь из
   машины по настоящим атакующим, без hover-цели/пешего подхода. Нужны
   оконная поза, текущее оружие, принятый source shot/HP и сохранение места.
   Отдельно мирный NPC, стена/союзник/выход/отмена. Проверка ещё впереди.
4. Производительность измерять в сопоставимой загруженной сцене. Изолированное
   время helper или render freeze не является gameplay FPS.

Первый вариант пассажирской стрельбы поддерживал пистолеты/ПП. По позднему
уточнению переделывается на текущее оружие/ответный огонь; старые результаты
не являются приёмкой нового контракта. Local authority сохраняется.
