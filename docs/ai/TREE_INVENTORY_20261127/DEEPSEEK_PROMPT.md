# Ревью системы деревьев и ресурсного инвентаря

Godot 4, рыцарская игра. Уже есть оптимизированные деревья MultiMesh, GPU-ветер, рубка мечом/топором, падение и физические брёвна, отдельный инвентарь на B.

Новая задача:
- красивый расширяемый инвентарь с карточками и рисунком предмета;
- во время открытия полностью блокировать движение и атаки, дать курсор;
- выбор предмета мышью показывает описание;
- закрытие B, Escape или крестиком мгновенно возвращает управление;
- каждое видимое физическое полено подбирается отдельно на E, исчезает только оно и даёт ровно 1 единицу;
- при массовой рубке сохранить лимит 32 физических тел и не потерять добычу;
- ускорить падение дерева и появление поленьев;
- улучшить low-poly дерево без заметного роста draw calls/FPS cost.

Предлагаемая архитектура: пауза SceneTree на время модального инвентаря, сам CanvasLayer PROCESS_MODE_ALWAYS; карточки генерируются по каталогу предметов; кодовая 2D-иконка бревна; overflow брёвен хранится в очереди и выдаётся физическими телами по мере освобождения лимита, каждое тело всегда wood_units=1; статические деревья остаются MultiMesh с одним GPU-шейдером.

Нужен краткий ответ: возможные регрессии, атомарность подбора, корректность паузы/ввода и обязательные тесты. Не предлагай внешние зависимости.
