# Карта города и окрестностей — 2026-09-09

Модуль `assets/maps/city_rebuild_v1/exploration_minimap.mjs` не зависит от Three,
внешних библиотек и серверных механик. Он не телепортирует героя, не создаёт
автопилот и не вычисляет маршрут: пунктир показывает прямое направление к метке.

## Подключение

```js
import {createExplorationMinimap,normalizeNativeInstances} from './exploration_minimap.mjs';
const minimap=createExplorationMinimap({
  onExpandedChange(open){releaseControls(); /* host guards: combat / camera / walking */},
  onWaypointChange(point){ /* optional world marker; point is null on clear */ },
});
const native=normalizeNativeInstances(instances,M); // THREE groups or raw manifest items
minimap.setWorld({
  bounds:{minX:-240,maxX:978,minZ:-420,maxZ:900},
  grid:topology.grid,cellSize:M,
  buildings:native.filter(o=>o.building),
  objects:[...native.filter(o=>!o.building),...newObjects],
  regions,water,trails,roads,
});
minimap.update({position:hero.object.position,yaw:hero.object.rotation.y,vehicles,actors});
```

Все координаты — **метры мира**, север сверху = -Z, восток = +X. `grid` имеет
старое начало 0,0 и масштаб cellSize=4.1. Его нельзя переносить вслед за новыми
отрицательными bounds. `normalizeNativeInstances` использует фактический
`transform.positionM` и текущий `footprint`, поэтому увеличенные корпуса банков
и другие правки размеров отражаются на карте автоматически.

Объект: `{id,name,kind,x,z,polygon,radius,building,poi}`. `polygon` = `[[x,z],…]`
или `[{x,z},…]`. Категории: building, bank, police, tree, forest, mountain, water,
fountain, monument, bench, lamp, landmark, object. Именованные достопримечательности
автоматически появляются в списке; для произвольного типа можно задать `poi:true`.
Путь/дорога: `{points:[[x,z],…],width}`. Регион: `{polygon,kind,color}`. Вода:
`{polygon}`. Динамика: `{x,z,yaw}` либо `{position:{x,z},yaw}`; NPC дополнительно
`kind:'police'|'civilian'|'boss'`, `hidden`/`active:false` убирают маркер.

## Управление и размещение

- Миникарта слева сверху, 16px, z-index4; большая карта z-index30.
- M/кнопка разворачивает; M/Esc закрывает. Разворот освобождает pointer lock.
- Клик по карте или названию места ставит метку. Метка сохраняется при сворачивании.
- Показаны расстояние в метрах, относительное направление, прибытие ближе 5м.
- Колесо/+/- приближают большую карту; drag/стрелки двигают; Enter ставит метку
  в центре при фокусе canvas; «Я» центрирует героя; «Весь мир» возвращает общий вид.
- Tab ограничен контролами большой карты, нативная активация кнопок доступна.
- Поля ввода не перехватываются. События карты не уходят в игровые кнопки/мышь;
  хост должен очищать уже удержанные клавиши через onExpandedChange.
- `get expanded`, `setExpanded(bool)`, `get waypoint`, `setWaypoint(point|null)`,
  `setVisible(bool)`, `dispose()` доступны снаружи.
- Меню сцены хост может скрывать миникарту через `setVisible(sceneMenu.hidden)`;
  повторное значение не переразмеряет canvas.

Статический слой строится только при `setWorld`, атлас не больше1536px по
длинной стороне. Базовый атлас содержит все объекты; крупные знаки/подписи
фильтруются по масштабу и расстоянию. Обновление динамики ограничено12.5Гц,
без своего requestAnimationFrame и без пересэмплирования рельефа каждый кадр.

## Железная дорога и читаемость карты

`setWorld({railways:[{points:[{x,z},…],width:2.2}]})` рисует две тёмные рельсовые
линии и поперечные шпалы. Станции передаются объектами `kind:'station'` с названием
и координатами. `update({trains:[{id,x,z,yaw}]})` показывает положение и направление
поезда; также поддержан `actors` с `kind:'train'`, дубликаты поездов по ID убираются.

Список мест сортируется: станции, горы/леса/озёра, уникальные достопримечательности,
затем повторяющиеся городские подписи. `mapPriority` позволяет явно задать приоритет.
Сами объекты с одинаковыми названиями сохраняются — удаляются только повторные ID.
Подписи на большой карте проверяются по измеренной ширине текста, не пересекаются
и ограничены16 на общем плане,32 в подробном. На общем плане банки/памятники/фонтаны
остаются значками и в списке мест; текст появляется при приближении.
Pure tests дополнительно проверяют сортировку, станции и непересечение подписей.

## Последние изменения пользователя — приоритетнее описания выше

- Миникарта **справа снизу**: right16/bottom16, на узком экране right8/bottom10.
- `setWorld({districts:[{id,name,polygon,center}],regions})` определяет район по
  точному полигону. Городские районы приоритетнее пересекающихся лесных зон.
  Название текущего района показывается в заголовке миникарты; большая карта
  называется «Карта города». Вне известных полигонов — «Окрестности».
- Постоянных подписей **внутри canvas больше нет**, включая подписи районов.
  Названия появляются в DOM tooltip при наведении на значок или footprint.
  Список мест справа и текст легенды сохранены.
- ПКМ по самой метке, в радиусе12 CSS px, удаляет её. Проверяется и метка,
  прижатая к краю миникарты. ПКМ в другом месте метку сохраняет. Кнопка × остаётся.
- Расстояние всегда выражено числом: «До метки: 123 м», включая0 м у цели.
  Слова «впереди/слева/позади/справа» убраны.
- Все22 текущих assetId зданий получают значки назначения: колонки банка,
  крест больницы, щит полиции, крыша дома, сумка магазина, оружие, лист типографии,
  камень ломбарда, ноты клуба, звезда, билет букмекера. В легенде те же рисунки.
- `vehicles[].color` или `skinColor` задаёт фактический цвет машины. Допустимы
  hex-строка #RGB/#RRGGBB или число0…0xffffff. Направление видно по лобовому стеклу.
- Старый ограниченный world atlas1536 больше **не растягивается**. Геометрия
  карты рисуется в кеш viewport в физическом разрешении canvas/DPR. Масштаб
  пересоздаёт векторный слой; перемещение использует64px запаса и обновляет кеш,
  когда обзор приближается к краю. Сетка рисуется только в видимых RC пределах.
  Статический слой отображается1:1 по физическим пикселям с округлённым сдвигом.
