# Невидимые преграды и перекат при выходе — 2026-09-10

Запрос пользователя в задаче01a087e2-a009-7873-a45f-8e1a4c2effc4: открытая плитка
на скриншоте Центрального округа блокирует проход; при выходе из машины на
скорости персонаж исчезает под землёй. Область — shared `/walk`18538.

## Установленные причины и исправления

1. `policeMask` резервирует882 клетки плитки9, в том числе проходы и открытую
   площадь. Старая `walkableMask` запрещает их целиком. В `native_pedestrian_surface`
   добавлено разрешение пешего движения по этой видимой плитке. Физические стены,
   двери, поезда и автомобили всё ещё проверяются отдельно. Сами grid/masks,
   placement reservations, полиция, мост, сервер и правила машин не изменены.
   CPU воспроизводит остановку прежним predicate и полный проход новым.

2. У52 exploration-скамеек и7столов-пикников был круглый collider, выступающий
   далеко за видимую мебель. Теперь это повёрнутые по yaw прямоугольники по
   настоящим размерам:2.60×.78 и2.70×1.98м. placementKeepoutPolygonCR сохраняет
   прежние круги отдельно для генерации окружения; все2440objects, их ID и
   координаты, а также внешние keepout-полигоны сохранены. Подробный аудит:
   `HIDDEN_COLLISION_AUDIT_20260909.md`.

3. `hero.tumblePose` прежде выравнивал кожу только относительно плоского root.
   Actual GLB regression нашёл проникновение в склон до0.359736м. Опциональный
   `{floorHeight}` теперь поднимает visualPivot по фактическим вершинам над
   мировой поверхностью. Физический root/yaw и длины костей сохраняются.
   `createExitPoseFloorSampler` кэширует .25м сетку; максимум36 дорогих запросов
   в3120testedframes, вместо отдельного world query на каждую вершину.

4. Host добавлял новый groundHeight под каждым шагом выхода. При пересечении
   берега тело сразу ставилось на дно, пока swimming был заблокирован transition.
   `createVehicleExitSurface` хранит непрерывную высоту/гравитацию, учитывает текущий
   этаж и держит перекатывающееся тело около поверхности воды. Door departure
   использует реальную базовую высоту машины, включая исправленный roll offset.
   При сходе с края exit не завершается до физического приземления.
   Swimming прогревается в detached-body фазе без применения позы к перекату.
   `createExitSwimHandoff` затем плавно передаёт высоту плаванию и не даёт холодному
   swim-lift уронить персонажа на дно, даже при позднем попадании в глубокую воду.
