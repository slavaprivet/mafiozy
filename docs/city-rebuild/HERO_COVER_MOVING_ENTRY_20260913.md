# Укрытия: движение и вход Ctrl — 13 сентября 2026

Последние жалобы пользователя: при движении вдоль укрытия снова видна голова; прижимание по Ctrl срабатывает только после нескольких попыток.

## Причины и исправления

- LIVE до закрытия собственной demo2 показал `active:false, reason:surface-too-low`: щель или низкая часть поверхности автоматически отключала attachment. Теперь сохраняется явное удержание Ctrl; при недостаточной текущей поверхности подсказка сообщает о просвете. Фактические лучи урона по-прежнему определяют защиту, щель не делает персонажа неуязвимым. Перемещение/исчезновение самой машины и прочие игровые запреты по-прежнему прекращают attachment.
- CPU воспроизвёл подъём головы до1.4м на маршруте высоты1.08→1.5→1.08м. Host сохраняет минимальную скрытую высоту до выхода из текущего укрытия и проверяет точку на1.2м впереди по направлению шага. Прицеливание использует текущую высоту. Текущая/предстоящая точки чередуются в прежнем бюджете около8 запросов в секунду, вместо удвоения raycast-нагрузки в кадре; в покое примерно1Гц.
- Реальный gait добавлял покачивание головы и мог загнуть колено отставленной ноги под пол. В cover pose компенсируется вертикальное покачивание, изменён только полюс IK проблемного колена. Стопы следуют шагу, длины костей не меняются, свободный C-присед не затронут.
- Вход выбирает высоту на настоящей точке attachment с её нормалью. AABB машины теперь только предварительная граница поиска. Если ближайшая точка не подходит, проверяются соседние точки на25/50см по той же стороне с проверкой всего пути и дистанции. Нельзя принять крышу вместо отсутствующей стенки.
- Камера, направленная почти вертикально или от препятствия, больше не запрещает вход. Направление только ранжирует подходящие поверхности.
- Явный Ctrl-запрос сохраняется на0.4с при краткой занятости/подходе, повторная проверка не чаще10Гц и только при разрешённом состоянии. Запрос истекает, обычная ходьба сама укрытие не включает. Повторный Ctrl выходит; Shift с движением выходит при свободной высоте, C остаётся отдельным приседом.

## Ограничения передачи

Производительность общей сцены не проверена. Собственная coverdemo2 фактически закрыта по новому разрешению пользователя оставить одну игровую вкладку и указанию Координатора16; дальнейшая очередь у Координатора17 `01a097a0-5d69-7660-9aa0-7845289a887e`. Пользователь у него выбрал приоритет общей оптимизации, новых GPU-вкладок не открывать. LIVE именно этих исправлений движения/приёма Ctrl ожидается после профиля. Старый LIVE адаптивной статической позы не подтверждает новые исправления.

Scoped файлы: hero_cover.mjs, hero_cover_host.mjs, hero_cover_pose.mjs, walk_preview.mjs (только cover broad maxY и Ctrl request hook), соответствующие tests. Другие world/NPC/vehicle/window/traversal hooks сохранены, серверная PvP защита не объявляется завершённой.
