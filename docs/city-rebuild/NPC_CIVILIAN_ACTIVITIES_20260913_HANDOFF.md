# Civilian activity source contract — Artist17

At this checkpoint `npc_civilian_activity_source.js` is implemented and source-tested but not yet loaded by world: shared-world wiring waits for the coordinator's camera-reload checkpoint. Do not present this as accepted LIVE behavior.

The module uses original residents and their existing civilian plans. A conversation owns two existing objects, computes two fixed meeting points ~1.97 metres apart, checks both approach segments using the existing capsule path predicate and physically advances at the normal resident speed. Speech and social effects come from the existing dialogue functions. Only after both arrive do they turn to face one another and converse for 6–9 seconds. A 600 ms finish phase returns them to their original shop/bench plan, with a cooldown against immediate repeated chats. Blocked approach, timeout, death, fight, panic, phone call, medical/custody/vehicle state or player conversation releases both participants. No nearby spectators are silently frozen as extra participants.

Bench reading adds presentation state only after existing physical bench arrival/reservation, with the existing rest deadline. Standing smoking pauses an eligible pedestrian on dry land for 7–11 seconds and then finishes and resumes their prior task. Active slots are bounded to three conversation pairs and two smokers, with an overall eight-record cap including reading. Selection runs every 1.4 seconds; smoking candidate inspection rotates through at most 24 original residents. This is the first local activity integration, not a completed city-wide population or background simulation. Root owns distributed density/background scheduling and business transaction integration.

The snapshot contract for renderer owner is `activity:{kind:'talk'|'read'|'smoke',phase:'approach'|'active'|'finish',since,until,partnerId}`. `since/until` use source milliseconds; finish resets `since` and lasts 600 ms. Approach keeps ordinary walking. `seat` continues to be the existing actual bench record. Death/cancellation produces `activity:null`; higher priority phone/custody/combat/water/vehicle poses remain authoritative.

`test_npc_civilian_activities.mjs` exercises the actual source capsule/path helpers against an explicit blocking polygon interval, both actors' bounded motion, same object/HP/task identity, facing, approach interruption by a new obstacle, completed conversation/smoke, death/call/fight/panic cleanup and bench release. The existing player conversation is preserved when ambient cleanup runs. Isolated six-active-actor CPU sample was about p50 .0049 ms / p95 .0075 ms; this is source-only CPU cost, not a populated scene FPS measurement. No additional GPU scene was opened.
