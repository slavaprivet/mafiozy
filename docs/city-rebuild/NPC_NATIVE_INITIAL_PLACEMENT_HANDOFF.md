# Native startup placement and physical water exit

`world.html` retains real NPC objects and IDs. On the first native navigation resolver registration, ordinary outdoor residents and eligible police are queued for validation. Pending actors are excluded from the source presentation snapshot and their main movement loop until placement succeeds. Existing riders, interiors, owners, story actors and gang bosses remain excluded from this adapter.

The former shared limit of 3200 candidates permanently abandoned later actors. Placement now resumes round-robin, at most 96 checks / 2 ms per simulation update (initial call 128 checks / 4 ms). Search expands through the bounded source map; candidates must be dry and body-free and avoid the *current* positions of other actors. No synchronous queue flush occurs in production. An actor already released to presentation is never relocated again by registration or reconnect. Diagnostics expose pending, exhausted, slices, moved and searchChecks. An exhausted actor is still hidden, rather than presented inside a wall or lake; no automatic endless retry is scheduled.

Water egress remains continuous physical movement. The egress-only pass predicate accepts legacy MAP=16 water and MAP=0 road, preserves native solid rejection and checks non-increasing depth along each swept segment. Normal routing still rejects water. Search admission supplies the NPC object to the shared fair route budget.

Validation: `test_npc_initial_placement.mjs` resolves 24 difficult starts in 285 slices / 27436 candidate checks, preserving objects and IDs. `test_npc_native_scene.mjs` resolves 32 real native blocked starts in 5 slices, with 1.21 ms maximum measured continuation slice on this run. `test_npc_native_water.mjs` tests actual source water/road tile rules, physical shore return, bounded resumable search, solid rejection and non-increasing depth. Live acceptance remains a separate check; the CPU scene fixture uses actual topology, landscape and placement colliders, not a full running renderer with every dynamic vehicle.
