## Сейфы

Физические полые корпуса, вращающаяся дверца, движущийся коллайдер, кодовый диск, подтверждённое состояние открытия/изъятия. Registry содержит24 фактически размещённых сейфа: `interior_safe_manifest.v1.json`, генерируется `node tools/interior_rebuild/audit_runtime.mjs --write-manifest`. ID привязан к ID здания/комнаты. Generic сейф не добавляется в исходное банковское хранилище: банковские7комнат и source механика сохранены.

`interior_interactive_safe`, `interior_safe_registry`, `interior_safe_source` связаны с source/наёмниками. Локальные standalone и разрешённый host local-preview используют отдельные устойчивые ledger; нельзя принять клиентское заявление о профессии за разрешение. Сервер `native_interior_safes.py` обслуживает POST `/world/interior-safes/{uid}` с actor binding, транзакционной одноразовой выплатой. Без серверного resolver реального отряда/расстояния действие отклоняется. Полный authenticated запуск, взлом наёмником и фактическая выплата в общей игре здесь ещё не приняты; monitor18538 не игровой backend.
