# Положение гражданской машины при серверном подтверждении угона

Исправление от 13 сентября 2026, владелец `/root/lifecycle_qa`, Artist17.

## Причина и контракт

`mafiozi_bot.py::civilian_hijack_start` ранее создавал машину точно в координатах и направлении игрока. Игрок в этот момент находится у двери, поэтому подтверждение сервера переносило автомобиль от его исходного центра. Транспортный клиент передавал верхние `x/y`, но авторитетный обработчик их не использовал.

Новый необязательный пакет: `civilian_carjack.d.carPose = {x, y, ang}`. Все три поля — конечные JSON-числа, без строк и bool. `x/y` в исходных клетках world, не native-метрах; `ang` в радианах. Сервер проверяет границы `.5..WORLD_MAP_COLS-.5`, `.5..WORLD_MAP_ROWS-.5`, расстояние от актуального серверного игрока не больше 2.5 клетки и консервативное свободное место относительно центров canonical quest cars (по обеим осям 1.2 клетки, как существующий серверный парковочный допуск). Направление приводится по модулю полного оборота.

Неверный явный пакет отклоняется **до** выделения ID или создания машины: `invalid_car_pose`, `car_pose_out_of_bounds`, `car_pose_too_far`, `car_pose_occupied`. Занятая, пустая либо разбитая canonical-машина не перемещается и не подменяется; её owner/driver/passengers/lock остаются прежними. Это только перевод local civilian traffic в серверную машину, не API перемещения существующих автомобилей.

Отсутствующий/null `carPose` сохраняет прежнее поведение старых клиентов — создание у игрока. Верхние `x/y/ang` не определяют положение авторитетного backend. В ответе `civilian_hijack_reply` и broadcast `quest_car_spawned` теперь есть проверенный `ang`, а `x/y` соответствуют выбранному положению. Политики моделей, окраски, ownership, наград, замков, HP и wanted не изменены.

`_preview_ws_server.py` использует ту же валидацию при наличии `carPose`; прежний preview-контракт верхних `x/y` оставлен для старых клиентов и существующих сценариев. Это тестовый WebSocket backend, не static monitor 18538.

## Файлы и проверки

- `civilian_hijack_pose.py` — чистая валидация, без изменения world.
- `mafiozi_bot.py` — импорт, scoped method/WS call/reply/broadcast.
- `_preview_ws_server.py` — optional pose parity.
- `test_civilian_hijack_pose.py` — 8 тестов PASS, команда `python -m unittest test_civilian_hijack_pose -v`.

Тест выполняет **реальные AST-тела** метода, normalizer и WebSocket-ветки из текущего `mafiozi_bot.py`, также текущую preview-функцию. Проверены корректное положение/направление, края карты/радиус, старый клиент, busy/no-player, malformed/NaN/Inf/bool/частичный запрос, overlap occupied/empty/wreck, отсутствие побочных изменений при отказе, broadcast и wanted только после успеха. Telegram-bot и производственный сервис не импортируются/не запускаются.

## Стоимость и ограничения

`outputs/civilian_hijack_pose_cpu_20260913.json`: 200 измерений после 20 прогревочных, один helper, одинаковые player/pose. Проверка выполняется один раз при угоне, не каждый кадр.

| Canonical cars | Legacy p50/p95, мс | Validated p50/p95, мс |
|---:|---:|---:|
| 0 | 0.0003 / 0.0003 | 0.0017 / 0.0017 |
| 100 | 0.0003 / 0.0003 | 0.0156 / 0.0161 |
| 1000 | 0.0003 / 0.0003 | 0.1373 / 0.1970 |

Сервер здесь не загружает actual native GLB/здания/дорожный planner: габаритный допуск — грубая защита от подмены canonical-машины, не доказательство точного отсутствия контакта с каждым объектом. Native сухую посадку и коллизии продолжает проверять source. Старый отсутствующий pose сознательно совместим, поэтому эта доработка не является полной серверной авторизацией local traffic identity.

Перезапуск backend, authenticated LIVE и FPS общей сцены не проводились. Производительность общей сцены не проверена. Для фактической публикации требуется согласованный перезапуск игрового backend с новым модулем и проверка Source→WS→snapshot вместе с клиентскими изменениями владельца `civilian_trips`.
