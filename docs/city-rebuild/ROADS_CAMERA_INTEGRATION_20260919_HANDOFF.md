## Контракт с Художником 17

`parking-anchors` возвращает реальные stable bay/lot ID и позиции source r/c/angle.

`parking-exit` принимает `from`, `carId` (alias `vehicleId`) и необязательный `profile:{halfLength,halfWidth}` **в source tiles**. Wrapper умножает размеры на 4.1; без explicit profile получает уже загруженную модель по carId, иначе pending. Возвращает физические source `points`, `accessRouteId`, `gearChanges` с `requiresStop:true`, ограничение 5 км/ч и `requiresLiveClearance:true`. Не делает Dijkstra и не перемещает акторов. Invalid profile/препятствие блокируют выезд.

NPC должен останавливаться перед сменой передачи и проверять динамические препятствия. Некоторые манёвры используют свободное соседнее место: занятую машину нельзя игнорировать. Дорожные данные сами по себе не означают готовую интеграцию всех NPC. Точки сервисных маршрутов также сохраняют gear/speed и исходные правила перекрёстка.
