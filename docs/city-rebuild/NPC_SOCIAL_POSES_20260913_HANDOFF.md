# Разговор, чтение и курение NPC — renderer

13 сентября 2026. Владелец `/root/lifecycle_qa`; source activities принадлежат `/root/civilian_visits`, подключение/перезагрузка — root Artist17.

## Контракт и результат

`life.activity = {kind:'talk'|'read'|'smoke', phase:'approach'|'active'|'finish', since, until, partnerId?}`. since/until — миллисекунды source. Для finish since обновляется на начало 600 мс завершения. При отмене источник передаёт null. Опциональный `speaker:false` даёт спокойного слушателя с движением головы.

Новый `npc_social_pose.mjs` вызывается scoped hook в `npc_actor.mjs` после исходной позы/сидения и до hit/death surface. Root/AI-координаты, HP, маршруты, таймеры и NPC identity не меняются.

- Talk: плавные попеременные жесты, небольшие движения головы и корпуса; фаза индивидуальна по существующему ID, поэтому собеседники не двигаются синхронно. Approach не включает руки даже при старом `life.talking`.
- Read: раскрытая бордовая книга с двумя кремовыми страницами; обе кисти держат края, взгляд опущен. Использует существующий seat rig и сохраняет бедро/стопы на скамейке.
- Smoke: сигарета с фильтром/угольком в правой кисти, цикл поднесения к лицу и опускания. Никаких новых частиц, дымовых emitter или игровых ресурсов.
- Death/fall/stun, оружие/удар, телефон, panic/flee/custody, посадка/поездка, прыжок, движение, вода, профессия и извлечение из машины имеют приоритет. Props скрываются сразу. Намокание/раны продолжает existing surface, никакого сброса материалов одежды.

Книга/сигарета создаются только при первом соответствующем действии. Обычный NPC не получает ни props, ни экземпляр overlay; talk не создаёт геометрию. На один видимый предмет 3 mesh. Если actor успел использовать оба предмета, кеш содержит 2 геометрии и 5 материалов. Освобождаются ровно один раз при dispose actor. Скрытые props не рисуются.

## Проверка и стоимость

`node assets/maps/city_rebuild_v1/test_npc_social_pose.mjs` — PASS, actual male/female GLB на обоих крайних ростах 1.65/2.05.

Проверены посадочные бедро/стопы; хват книги (центр→кисть .131–.163 м по росту); исходные длины/масштабы всех костей, конечные матрицы и неподвижный root/yaw; непрерывность жеста; отсутствие props/legacy рук при approach; finish/expiry; телефон, паника, custody, flee, shallow water, vehicle, melee, jump, walk, death и реальный TT weapon; ноль новых THREE Vector/Quaternion/Matrix/Geometry/Material/Mesh/Group во время прогретого apply, постоянное число props и корректный disposal. Existing `test_npc_activity_pose.mjs` через offline preload тоже PASS, включая реальные подошвы, телефон, посадку и вставание.

Отчёт: `outputs/npc_social_pose_20260913.json`. Изолированный overlay, 80 вызовов/rig: active p50 .052–.057 мс / p95 .067–.095 мс; idle p50 .0002–.0003 мс. Первоначальная реализация с обновлением всего actor на каждом звене IK имела p50 .087–.095 мс / p95 .108–.146 мс; замена внутренних обновлений на соответствующую ветку костей уменьшила стоимость, позы и тесты сохранены. Базовая анимация/сидение исключены из замера самого overlay и могут иметь собственные выделения памяти.

GPU, visual LIVE и source разговор целиком не проверялись этой задачей: игровая вкладка принадлежит текущему центральному прогону координатора. Производительность общей сцены не проверена. Перед визуальной приёмкой нужны согласованная перезагрузка с source activity wiring и проверка жестов/размера предметов в реальной камере.
