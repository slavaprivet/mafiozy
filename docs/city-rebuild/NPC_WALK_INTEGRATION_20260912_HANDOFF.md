# Художник16 — NPC в общей игре, 12 сентября 2026

Поручение пользователя: NPC исходного world в walk; движение без воды/стен/машин, плавание, бой, поездки и посадка, ранения/кровь/смерть, отдельные реакции полиции и свидетелей. Работа в shared checkout, без reset, коммита или push. Координатор16 и его mercenary hooks сохранены; отдельная AI вместо source не создавалась.

## Внедрение

- Существующие source IDs, AI, HP, индивидуальные боссы, задержание и транспорт остаются владельцами состояния. Рендер NPC использует общий мужской/женский персонаж, рукопашные/оружейные позы, воду и поверхность ран.
- Native navigation теперь отдаёт явно подтверждённую land/road. Старые стены MAP не перекрывают новую свободную поверхность; действующие solids, машины, вода и ограничения районов сохраняются. Обычным мирным маршрутам запрещено выбирать дорогу/воду; экстренные маршруты сохраняют свои разрешения.
- Местные специальные NPC и cityCops физически выходят из воды через ограниченный продолжаемый поиск, без телепортации. Плавание включается глубиной. Защищённые death/custody/transport-фазы не перехватываются.
- Гражданские поездки используют настоящую водительскую дверь/сиденье, плавные board/exit позы и проверку коридора. Исключается только собственный автомобиль. Непроходимый выход ждёт, машина проверяет native-препятствия. У автобусных ожидающих устранены преследование уехавшего автобуса и бесконечное накопление.
- Свидетели: FOV140°, дальность, LOS/слух, накопление подозрения при оружии, отход/звонок с ограничением повторов. Полиция различает увиденного нарушителя и услышанную стрельбу; потеряв цель, проверяет последнюю замеченную точку. Существующий розыск, прямые атаки и арест сохраняются.
- Новый `npc_native_perception.mjs` читает текущий collision index города, высоту препятствий, автомобили и рельеф. Низкая лавочка/навес не равны высокой стене. Высоты учитывают стойку, присед, положение лёжа и плавание. Подключён registerWalkNpcPerceptionResolver, очищается на pagehide, counters доступны в body.dataset.npcWorld.perception. Никаких новых draw calls.
- Кровь/раны привязаны к реальному skinned-контакту: кожа получает рану, одежда — рванину; явный запрет knockdown и блок сохраняются.
- Исправлена цепочка выстрела: уже принятый физический контакт не отбрасывается плоскими legacy-конусами/стенами. Реальное дуло сходится с лучом прицела; препятствие возле дула всё ещё блокирует. Native blockers включают static ray index, fleet и source traffic. Прицел вычисляется только после source-допуска выстрела, перед единственным расчётом разброса. Отклонённые автоматические попытки не скинят толпу.

## Открытые пределы

- Нет работающего backend/WS в этой вкладке. Новый civilian_suspicion handler и server cop/player FOV+legacyLOS проверены CPU; перезапуск и authenticated LIVE не выполнены. Сервер не имеет реестра гражданских и native геометрии. Typed suspicion low-trust/observe-only; старые отдельные witness flags не отменены.
- Серверные worldCops под server navigation: клиент не подменяет им движение. Native shore routing для них требует серверного контракта.
- Планировщик автомобильных поездок использует source roads; native-коллизия безопасно остановит конфликт, но обход каждого нового здания не гарантирован. Целый визуальный цикл поездка→вход в новый интерьер→выход и постоянные автобусные пассажиры не приняты.
- Полную видимость каждой посадки/плавания/рукопашки в загруженной общей сцене этот GPU-слот не покрывает; CPU/GLB проверки не заменяют такой цикл. Дальнейшие GPU-прогоны через координатора.

Дополнительный аудит стоимости принятого выстрела завершён без изменения production-кода: `NPC_CONTACT_RAY_PERF_AUDIT_20260912.md`. Рабочее ленивое вычисление только допущенных выстрелов сохранено. Все три субагента завершили работу; дополнительного GPU-прогона после освобождения слота не было.
