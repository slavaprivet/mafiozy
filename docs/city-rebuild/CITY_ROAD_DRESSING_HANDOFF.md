## Контракт парковок и въездов

`createCityRoadDressingPlan({..., accessKeepouts:[{id,minX,maxX,minZ,maxZ}]})`
принимает мировые AABB в метрах. Это полный driveway и swept mouth на дороге,
не только площадка парковки. Некорректные прямоугольники отклоняются.
Точный SAT исключает `edge`, `center_dash`, `lane_dash`, пересекающие устье;
стойки и концы переходов также резервируют эти области. Результат возвращает
`accessKeepouts`, `stats.accessKeepouts`, `stats.accessSuppressedPaint`.
Обычный `keepouts` продолжает резервировать площадки/проходы для стоек.

Координатор подключил контракт в worker/wrapper с новым parkingPlan.
`--shared` тест воспроизводит actual worker с предварительным резервом
парковок до procedural decor и проверяет все реальные устья парковок.
Ни одну пешеходную дверь не выдумывали автомобильным въездом.

## Источник и сохранение мира

Routes содержит 207 принятых дорог из addendum текущей
`topology_for_placement.json`; SHA256 исходника
`dbd287d1aa692d3706ae7cc5c1cba17972538e248805100f19cd95a2ef9f5a0f`.
Берутся реальные `land_fragments_grid_cr`, класс, ширина и число полос.
245 сухопутных фрагментов не включают отложенные подводные соединения.
В рантайме исходный внешний файл не нужен. Нативный масштаб 4.1,
ID, физическое покрытие, защищённая полиция и красный мост сохранены.

Граф строится из пересечений авторских осей и T-примыканий, где источник
заканчивает ось у края проезжей части. Связность реального roadMask проверяется
BFS. Для каждого входа вычислены направление, полосы, ближайший следующий
перекрёсток, принадлежность к главной/второстепенной дороге и разрешённые выходы.
Главная определяется классом, числом полос, затем непрерывностью коридора;
равнозначные местные улицы используют помеху справа. Односторонность в исходнике
не задана: она не выдумывается. Узкие одноосевые проезды остаются общими для двух
направлений. Принято правостороннее движение в координатах мира; старая modulo-
схема world.html не переносится на произвольные направления native-улиц.

Каждый поворот проверен по всей траектории с шагом около 0.55 м: центр на
настоящем асфальте, кузов проходит `carFits` с действующими collision bodies.
Связи между перекрёстками проверены аналогично с шагом 1.1 м и не прыгают между
разными индексами полос. Повороты в тупики, разрывы и непроходимые ветви удалены
рекурсивно. Левый поворот только из внутренней полосы, правый — из внешней;
развороты не добавлены. Граф не меняет старые fleet/server-механики автоматически.

## Подключение и plain-данные worker

```js
const plan = createCityRoadDressingPlan({
  topology, landscape, railPlan, instances, keepouts,
});
const roads = createCityRoadDressing({THREE, plan});
scene.add(roads.object);
roads.update(dt, {time, focus}); // абсолютные секунды; focus = {x,z}
// roads.colliders -> действующий индекс героя/машин
// roads.mapFeatures -> миникарта, только стойки и сигналы
roads.dispose();
```

`instances` принимает placements либо THREE groups с userData.instance.
`keepouts` — мировые `{minX,maxX,minZ,maxZ}` нового декора. Входы, clearance,
footprint и collision bodies переданных зданий исключаются автоматически;
полотно и платформы исключаются через railPlan. Коллайдеры стоек используют
прежний `polygonCR` и абсолютные `minYM/maxYM`, радиус 0.2 м.

После удаления трёх проверочных функций `isRoad`, `paintSafe`, `safeSign`
весь результат проходит `structuredClone`. Граф доступен как:

- `plan.trafficPlan`: версия, drivingSide, roadRules, components, junctionRules,
  lanes, connections, turns, crosswalks, signalHeads, stats;
- `plan.junctionRules`: те же правила перекрёстков;
- `plan.laneGraph`: lanes, connections, turns.

Каждый approach содержит rule (`signal`, `priority`, `yield`, `priority_right`),
stopPoint, outward, signalId/signId, crosswalkId, allowedTurnIds,
navigableOutgoingLaneIds, nextJunctionId, deadEnd, boundaryExit.
Каждый turn содержит from/toApproachId, from/toLaneId, kind, points с yaw,
yieldTo, priority, axis, offset и signalId. yieldTo включает главную дорогу,
помеху справа для равнозначных местных улиц и встречное направление при левом
повороте. Signal offset совпадает с видимой головой и renderer.update(time).

Чистый API для подключения поведения автомобилей:

```js
import {nearestTrafficApproach, evaluateTrafficApproach}
  from './city_road_traffic_plan.mjs';
const approach = nearestTrafficApproach(plan.trafficPlan, {
  x: car.x, z: car.z, yaw: car.yaw, maxDistance: 35,
});
const permission = approach && evaluateTrafficApproach(plan.trafficPlan, {
  approachId: approach.approachId,
  time, // тот же clock, что у roads.update
  turnId, // необязателен; выбранный манёвр проверяется по связям
  occupiedTurnIds, // реальные занятые конфликтующие траектории
  occupiedCrosswalkIds, // реальные пешеходы на переходах
});
// permission.allowed, reason, stopPoint, yieldTo, allowedTurnIds
```

Причины: unknown_approach, turn_not_allowed, pedestrian_crossing,
traffic_signal, yield_to_traffic, no_connected_exit, clear. nearestTrafficApproach
проверяет направление машины и её положение перед стоп-точкой. API не вычисляет
занятость из воздуха: вызывающий код передаёт действующие машины/пешеходов.
Самостоятельное подключение к server/fleet в рамках этих модулей не выполнялось.

## Осмысленная разметка и знаки

Продольные линии исключены из площадей всех 490 перекрёстков. Перекрывающиеся
параллельные авторские фрагменты получают одного владельца краски. У местных
улиц убраны краевые линии: их край задаётся бордюрами, поэтому издали больше
нет частой белой сетки. Центровые пунктиры и четырёхполосные разделители следуют
реальным улицам. Точный SAT не даёт даже узкой полосе срезать тротуарный угол.
Дополнительная выборочная проверка исключает рельсы и protected-зоны.

Стрелки только на главных/сборных улицах, не чаще 65 м в одной полосе. Они
показывают только проверенные манёвры, пропускаются перед резкими изгибами и
рисуются целиком: если не помещается наконечник, отменяется весь символ.
Зебры тоже атомарны. Их оба конца ведут к сухим тротуарам с пешеходным запасом,
не к газону, воде, зданию или платформе. Стоп-линия/линия уступания находится
до соответствующей зебры и поперёк входящей половины проезжей части.

16 основных перекрёстков получили полные светофорные группы: безопасная стойка
есть у каждого действующего входа и обеих осей. Если группу целиком не поставить,
работают явные правила главной/второстепенной дороги. Цикл 44 с: зелёный 17 с,
жёлтый 3 с, общий красный 2 с, затем противоположная ось. Конфликтующих зелёных
нет. Левый поворот на зелёный уступает встречным прямым/правым траекториям.
Пиктограмма перехода на стойке есть только при реальной зебре на этом подходе.

Жёлтый ромб обозначает главную дорогу, красно-белый перевёрнутый треугольник —
уступание, синий знак — настоящий переход. Главный знак повторяется не чаще
180 м одной улицы. Ограничение 40 стоит у въездов в город. Указатель вокзала
повёрнут к действительному вокзалу. Стойки стоят справа от входящего движения,
лицом к водителю. Корпуса — teal/limestone/латунь, дорожные символы узнаваемых
обычных цветов. Знаки без основания в правилах не добавляются.

## Оптимизация и проверка

Краска объединена по двум материалам и чанкам 128 м. Оборудование инстансировано
по форме и чанку. Детали вблизи сохранены. Линзы используют три общих emissive-
материала, матрицы обновляются только при смене фазы. PointLight нет. Distance
culling: 360 м плюс радиус чанка, затем штатный frustum culling Three.
`stats.visibleDraws` — разрешённые батчи до frustum; настоящие GL calls нужно
смотреть в renderer.info. Живую сцену проверяет координатор.
