# Первый нативный выбор рендера, 26 сентября 2026

Координатор 20 последовательно запустил **один** экземпляр реальной сцены
на Godot 4.7.2 / GTX 980: Compatibility (OpenGL 3.3), Forward+ (Vulkan 1.3.280)
и Mobile (Vulkan 1.3.280). Старый экземпляр закрывался перед следующим.
Все три фактически выбранных режима подтверждены журналами движка.

Это **не приёмка S01 или производительности игры**. Сценарий: неподвижная камера,
1280×720, восемь зданий и восемь фонарей, герой в стойке, без NPC/машин/интерьеров.
На каждый профиль два секунды прогрева и 240 кадров по монотонным часам.
Снимки сохранялись после измерения. Синхронизация с экраном ограничивает результат
примерно 144 FPS; из этих цифр нельзя выводить запас GPU или скорость полной карты.

## Сопоставимые исходные настройки

ACES, солнце 1.5, ambient 0.65, white 6, без MSAA. Одинаковые модели, материалы,
коллизии, положение камеры и 188 168 primitives по счётчику движка:

| Фактический renderer | p50 / p95 / p99, мс | draw calls |
|---|---:|---:|
| Compatibility | 6.933 / 7.477 / 7.736 | 1016 |
| Forward+ | 6.937 / 7.138 / 7.655 | 965 |
| Mobile | 6.940 / 7.136 / 7.375 | 516 |

Не сравнивать количество draw calls между архитектурами как готовый процент
ускорения. Полные протоколы находятся в `outputs/godot_lighting26*/measurements.json`;
в том же каталоге — четыре настоящих PNG каждого режима. Инструмент
`outputs/godot_lighting_compare26.gd` замораживал физику героя только для этого
стационарного сравнения, затем возвращал управление.

## Визуальный результат и решение

В Compatibility светлый тротуар остаётся полностью белым, даже при уменьшении
солнца до 0.7, ambient до 0.45 и смене Filmic на ACES. В исходном кадре
`01_baseline.png` 6.89% пикселей области y=250..609 были RGB 255 во всех каналах.
Это измерение участка изображения, а не всей сцены или отдельного материала.
Таким образом, прежнее утверждение root об исправлении пересвета одной настройкой
white=6 было **преждевременным**. Пользователь справедливо указал на дефект.

В Forward+ и Mobile при тех же источниках света и байтах моделей тротуар сохраняет
бежевый оттенок, фасадные детали видны, исходные цвета героя не теряются.
Root просмотрел настоящие кадры обоих Vulkan-режимов. Предварительный настольный
профиль — Forward+, ACES, MSAA 4×; MSAA также проверена в отдельном профиле.
Это рабочий выбор для следующих проверок качества, **не доказанное преимущество
в производительности над Mobile** и не окончательная конфигурация релиза.

Финальные процедурные материалы поверхности добавляются после этого сравнения;
их новый живой прогон фиксируется отдельно. Не приписывать этим таблицам стоимость
ещё не подключённых материалов, движения, SSAO или будущего населения.

Остаются открыты: S00 тяжёлый исходный маршрут и фактический host snapshot,
полный trace collector / overhead ON-OFF, экспортированный релизный запуск,
RAM/VRAM, полноценная графическая и игровая идентичность. Материалы source GLB
для компенсации освещения не перекрашивались.

Справочные параметры сверены с [Godot Environment](https://docs.godotengine.org/en/stable/classes/class_environment.html)
и [ProjectSettings](https://docs.godotengine.org/en/stable/classes/class_projectsettings.html).
Предпочтение профиля основано на реальных кадрах, а не только на документации.
