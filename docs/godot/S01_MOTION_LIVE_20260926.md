отдельными проверками. Прыжковая/боевая анимация, полноценная постановка ног на
склонах и лестницах ещё не перенесены.

## Защита от ложного старта

Перед появлением объектов main проверяет схему, IDs, размеры, полигональные
коллизии, ресурсы и материалы; использует только целиком подготовленный набор.
Независимые реальные main instances: неизвестная схема, отсутствующий GLB здания,
отсутствующий герой, неверный colorSpace материала и неизвестный тайл все отклонены
с `preview_ready=false` и **нулём 3D-узлов**. Затем корректная сцена запускается.
50 отрицательных случаев чистого валидатора и повтор всех 27 коллайдеров / 961
клетки actual physics проходят. Ожидаемые ошибки испорченных fixtures подписаны;
они не являются авариями обычной сцены. Временные тестовые файлы удалены.

Ни один из этапов S00–S04 не объявлен полностью принятым. Следующие обязательные
границы — release/recorder, полный source snapshot и индивидуальные входы/интерьеры.
