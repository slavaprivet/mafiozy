# Оконные рамы Палаццо — версия45

Исправлены две причины зависших окон. Граф опор теперь проверяет отдельные
физические детали рамы, а не заполненный воздухом общий прямоугольник окна.
Оторванные перекладины переходят в обычную физику. При потере стены старые
статичные стёкла и контуры Broken_Glass_Edges выключаются; осколки завершают
обычный цикл. На целой движущейся двери разбитый контур следует за створкой.

Основа — принятая43. Изменены только building_support.gd, palazzo_glazing.gd,
номер сборки main.gd и пять пунктов preview_updates.json. Дверь v5, игрок,
навигация, дороги, вода, декор, транспорт и три исходных NPC сохранены.
Новые здания, следующий пакет C4 и повреждения машин сюда не входят.

Нативная проверка Godot4.7.2:

- Исходная ошибка воспроизведена: 7457 проверок, ноль ошибок. После трёх
  обычных компонентных взрывов перекладина остаётся висеть без пути к земле.
- Исправление: 8074/0, падение той же детали на 1,194 м. Все действительно
  опирающиеся части сохранены на шести контрольных этапах; исходная геометрия
  совпадает. Компонентные взрывы не называются настоящими выстрелами RPG.
- Полная игра: 61/0 — настоящий RPG с расходом одного заряда и совпадающими
  идентификаторами контакта/урона; K убирает 28 старых стёкол и контуров;
  реальные рамные тела падают; игрок проходит через бывшую стену только W;
  J восстанавливает 28 новых окон. Капсула игрока неизменна: 1,9 м / радиус0,30 м.
- Дверь E: 109/0. Объединённая проверка стекла с новыми опорами: 173/0.
  Все итоговые процессы завершились, stderr пуст. Снимки просмотрены.
