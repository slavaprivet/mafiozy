# Native articulated character body — bounded prototype, 2026-09-27

Owner scope: `scripts/character_physics/exit_ragdoll_body.gd` and its native test. Main/player/transport integration and recovery admission belong to the coordinator. This module never writes the actor, visual skeleton, identity, transport lease, HP or damage receipts.

## Physical model and ownership

`configure(skeleton, parent, options)` prewarms 16 `RigidBody3D` capsule proxies and 15 `Generic6DOFJoint3D` nodes from the **actual 28-bone player skeleton**, its global canonical rest transforms and actual scale. Pelvis, spine, chest, head, upper/lower arms, hands, thighs, shins and feet are simulated. Other bone/socket frames follow their nearest simulated ancestor. The source pelvis bone pivot is near the feet; the physical pelvis capsule is centered between the actual hip origins. Use `anchor_world` or `pelvis_body_transform` for its COM, not the bone pivot.

Normal walking leaves every body frozen, with disabled shape and layer/mask 0; there is no module `_process` or `_physics_process`. Start reuses the pool and rebinds joint references. World/car contacts remain enabled. All pairs within this **one** articulated body are excluded: approximate capsules overlap in the authored tuck and competing internal contacts destabilized the constraint solver. Different ragdolls are not mutually excluded. This is not a flesh/self-contact simulation or a skin collision hull.

Mass is 75 kg by default (options admit 20–200), distributed over the 16 parts. The current candidate fits capsules once during configure to actual weighted rest-skin vertices, assigning each vertex to its dominant bone or nearest simulated ancestor, centering the capsule and bounding its axial/radial extent. This is a conservative rigid proxy approximation, not imported anatomical collision assets or a dynamic skinned hull. Friction .65, restitution 0, CCD enabled, angular damping 2. The physics engine supplies gravity, contacts and solver forces. There is no authored rolling rotation or forced final fallen pose.

Knees and elbows have **canonical-rest angular references**, independent of initial fold. Source local +X knee flexion is limited nominally to −5..145 degrees; elbow flexion to −145..5. GodotPhysics measures the inverse relative frame, so server bounds have opposite signs. Other joints retain damped finite limits relative to the outgoing pose. Linear anchors start exactly at that pose. These are **soft numerical limits**: hard straight-leg landing still showed about .45 rad transient knee extension in this test. Do not call this a complete anatomical constraint model or promise zero backbend. Contact and joint error checks remain separate from visual skin correction.

## Host API

- `configure(Skeleton3D, Node3D, options={}) -> {ok,error,...}`: same live physics world; options `total_mass_kg`, `collision_layer` (256), `collision_mask` (1 plus own layer), `exceptions` (bounded 16 collision objects, actor capsule normally). Call during load, outside physics query flush callbacks.
- `capture_world_frames() -> Dictionary[String,Transform3D]`: current actual outgoing pose, including visual hierarchy transformations.
- `start(world_frames, inherited_linear_velocity, outward_impulse_ns=Vector3.ZERO, inherited_angular_velocity=Vector3.ZERO, reference_point=Vector3.ZERO) -> {ok,error,...}`: validates all original bone names, uniform unchanged scale, lengths and finite frames before mutation. Each part receives `v_ref + omega.cross(part_COM-reference_point) + outward_impulse_ns / total_mass` and angular velocity `omega`. A desired outward 2.4 m/s increment on 75 kg is an impulse of 180 N·s. Defaults retain the original three-argument behavior. Angular speed is bounded to 30 rad/s and every resulting segment velocity to 80 m/s; invalid values reject before any start mutation. Summed momentum is `M * (v_ref + omega.cross(system_COM-reference_point)) + J`, **not** necessarily `M*v_ref+J` when the reference is not the system COM. Host owns admission/direction/vehicle point-velocity sampling and must pass the point at which `v_ref` is defined.
- `snapshot() -> {valid,active,...}`: active snapshot includes `bone_world_frames`, `root_world_transform`, `pelvis_body_transform`, `anchor_world`, `max_linear_speed`, `max_angular_speed`, `contact_count`, `sleeping_count`, `settled`, `max_joint_anchor_error_m`, `paused`, body/joint counts, total mass. Complete bone scales are preserved. `settled` requires external contact, linear speed <.12 m/s, angular speed <.3 rad/s and anchor error <.035 m; **no timer or standing-support claim**. Host should require sustained stability and admit a clear supported standing volume separately.
- `apply_impulse(world_point, impulse_ns, event_id="")`: nearest capsule surface, local off-center torque through native `apply_impulse`; rejects >.75 m from body or >10000 N·s. Event id is returned only; common authority bridge owns dedup and HP.
- `owned_bodies()` / `body_rids()`: bounded exclusions for camera and recovery queries.
- `stop_preserve()`: freezes, disables collisions, retains active frozen snapshot for get-up blending. Pending solver transforms cannot drift the frozen snapshot. `freeze_at_rest()` first requires settled. Neither method commits gameplay recovery.
- `reset()`: disables simulation, returns to inactive prewarm, reuses node identities. Call before another start, including interrupted recovery.
- `dispose()`: removes owned pool only, idempotent. Outside-tree snapshot rejects and stop skips detached bodies without reading invalid global transforms.

## Primary API evidence

[RigidBody3D](https://docs.godotengine.org/en/stable/classes/class_rigidbody3d.html), [Generic6DOFJoint3D](https://docs.godotengine.org/en/stable/classes/class_generic6dofjoint3d.html), [PhysicsServer3D](https://docs.godotengine.org/en/stable/classes/class_physicsserver3d.html) document frozen rigid bodies, local-offset impulses and independent 6DOF reference frames. [Skeleton3D](https://docs.godotengine.org/en/stable/classes/class_skeleton3d.html) bone global poses are skeleton-relative, hence multiplication by skeleton world transform. [GodotPhysics 6DOF source](https://github.com/godotengine/godot/blob/master/modules/godot_physics_3d/joints/godot_generic_6dof_joint_3d.cpp) establishes inverse angular-reference sign, nonzero angular force-limit requirement and positional correction: setting linear-limit restitution to zero removes anchor correction; it is not contact material bounce.
