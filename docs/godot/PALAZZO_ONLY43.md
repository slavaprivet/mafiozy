# Палаццо — версия43

Принятая сцена `s01-20261001-palazzo-only43` оставляет только отдельный Палаццо.
Все восемь прежних зданий, их коллизии, интерьеры и modular30 исключены из
активной сцены и навигации. Исходные модели и raw block сохранены. Дороги,
303 водные клетки, 8 объектов декора, транспорт и 3 исходных NPC сохранены.

E выбирает неподвижный дверной проём по направлению камеры с расстояния до3м.
Из положения рядом с открытой створкой можно закрыть и снова открыть дверь,
не меняя положение персонажа. Тело непосредственно в конечном положении
двери и другие препятствия по-прежнему учитываются. Только инициатор временно
исключается из дуги движения; исключения очищаются при завершении/сбросе/выходе.

Проверка Godot4.7.2 Forward+ на полной текущей сцене: 53 проверки состава и
движения NPC, 109 проверок двери, 4 измеренных реальных команды E; ошибок0,
stderr пуст. Root просмотрел actual GPU PNG для закрытой/повторно открытой
двери и двух общих видов квартала. Команды введены через Viewport.push_input;
позиционирование персонажа в тестах — явная подготовка, не проверка ходьбы.

Сопоставимый замер: та же камера/настройки/3NPC, 120 кадров прогрева и600
замеров. В покое p95 10.011→9.942мс. Стоимость самой команды E после оптимизации
3.421–3.789мс вместо8.621–9.536мс первого исправления. Это всё ещё примерно
на2мс больше прежних1.309–1.661мс: добавлена полная проверка конечной позы,
стекла и других акторов. Кадры во время движения сопоставимы; снижение числа
зданий не используется как доказательство оптимизации двери. Процесс RSS
не измерялся; полный город287NPC этим прогоном не проверен.

Данные: `outputs/coordinator26_palazzo_only43/ACCEPTANCE.json`, runs/gpu02,
runs/door_v5_gpu01, runs/perf_door_v3_02, runs/perf_door_v5_01.
Повторяемые проверки: tools/godot/qa_palazzo43/{scene,door,performance}.gd;
вызов Godot с --path принятой игры --script абсолютный файл проверки --
--qa43-out=абсолютная_новая_папка. GPU/движки запускать последовательно черезroot.

Постоянный запуск и F5 используют `godot/current_version.json`.
Новая серия разрушаемых зданий, car_damage42, dive39/return41 и новые исправления
рам/C4 не включены в43. Чужие shared WIP сохранены. Frozen игра запускается
из локальной папки outputs; исходники текущего изменения отдельно сохранены
в godot/mafiozi_walk, а архивные ресурсы не удалены.
