## Поведение

Локальный новый сеанс использует все14 оригинальных моделей, исходные профили
стрельбы и конечные патроны. Q выбирает оружие, ЛКМ стреляет, ПКМ прицеливается,
R перезаряжает, C/Z переключают присед/положение лёжа. Низкий потолок физически
блокирует вставание. При неактивном управлении и после смены владельца позы
выстрел не допускается. Первый клик по игре включает управление без выстрела.

G при наведении на открытый багажник переносит оружие из рук. E по настоящей
модели внутри сразу берёт этот экземпляр в руки — позднее прямое уточнение
пользователя. Предыдущее оружие остаётся в инвентаре. UID и патроны сохраняются.
Закрытый или движущийся багажник не принимает предмет и не превращает G в бросок.
Изменяющаяся подсказка показывает занятое/свободное место из100. Одновременная
подсказка E закрыть скрывается при наведении на предмет без дополнительного
покадрового поиска по геометрии. Таблички посадки/выхода подняты с1.7 до2.15м.

Стоимость по точному объёму габаритов моделей: Наган3, ТТ3, револьвер4, Deagle4,
золотойColt4, обрез4, дробовик6, Uzi7, золотойUzi7, АК10, M1610, Томпсон7,
снайперская18, РПГ13 — всего100. АК15 был примером, не фиксированным правилом.
Одна базовая единица каждому типу, остальные86 распределяются по объёму методом
наибольших остатков. Общий масштаб всех моделей подбирается по настоящему
багажнику: .1955807848 для стартового hatchback. Все14 лежат на полу,91пара не
пересекается; исходное соотношение размеров сохранено. Ground-модели сохраняют
исходный масштаб .368; конечные места учитываются ещё во время их падения.

## Исправления, найденные при интеграции

- Патроны фиксируются только после текущей позы, идентичности экземпляра и
  допуска всей очереди. Визуальные эффекты выпускаются до внешних уведомлений;
  повторное нажатие без отпускания не создаёт лишний полуавтоматический выстрел.
- Исторические данные выстрелов не исчезают, если первый обработчик сменил позу;
  удаляемый владелец прекращает последующие уведомления. Неудачная запись
  инвентаря не меняет состояние оружия и не создаёт эффекты.
- SourceFire после выстрела/перезарядки возвращает целочисленные float. Store
  принимает их без округления, проверяя конечность, профильные лимиты и безопасный
  диапазон sequence; дробные значения и NaN/Inf отклоняются.
- Отрицательный просроченный cooldown из раннего source reload return превращается
  в0 только на границе хранения. Следующий исходный Fire.step сам начинает с
  max(0,cooldown): для всех14 проверено полное совпадение дальнейших состояний и
  выстрелов. Исходный Fire-порт и патроны не изменялись.
- Закрытие настоящей сцены безопасно освобождает пулы эффектов/моделей; старт
  луча внутри препятствия не становится выстрелом сквозь стену.
