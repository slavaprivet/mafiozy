# Artist22 unpaused observer — executable CPU-reviewed prerequisite

This is an implemented diagnostic observer, not a registered NPC frame, native
population admission, a complete mercenary export, or a LIVE/FPS result.
Original application files stay byte-identical. Six exact original HTTP responses
are transformed in memory; seven route/navigation/traffic/rail dependencies are
served unchanged with reviewed byte hashes. The runner never enables Debugger,
pauses source, forces a lazy getter/ground call, or overrides clocks/RNG/storage.

## Components and result boundaries

- `tools/godot/npc_observer_transform.mjs`: six-path raw-SHA allowlist,
  original/instrumented hashes and every edit's byte offsets and hashes. Source
  scope/return/throw/receiver and short-circuit semantics tested using actual
  source functions. Source row fields copied by instrumentation are freshly
  constructed audited plain row fields; this is not a generic Proxy reader.
- `tools/godot/npc_observer_collector.mjs`: bounded preallocated primitive
  events, strict scopes, tagged values and exact float64 overlay. Unsupported
  values, string/event/scope overflow latch HOLD, with no source references.
  Snapshot seals and serializes owned buffers later outside source execution.
- `tools/godot/read_npc_observed_roster.mjs`: exact-byte and host-metadata-bound
  read API, closed registration/placement scopes, source-order pre-queue rows,
  natural typed IDs. Duplicate IDs do not prove object alias identity. Missing
  IDs/rows/scopes stay PARTIAL/ABSENT. No birth history, present-frame state,
  source authentication, ground, HP, ownership or physical admission is inferred.
- `tools/godot/capture_npc_unpaused.mjs`: prepare-only by default; a fresh
  exact-plan Root22 GO is required to launch. It uses the previously reviewed
  frozen `npc_capture_lifecycle.mjs`, new empty browser profile, original /walk
  entry, original-response hash gates, bounded waits and owned-process cleanup.
  It discards mutable caller buffers and regenerates the reviewed byte closure.

The runtime packet includes gate/read return or throw markers, naturally visited
ground, lazy scalar reads and paired query scopes. Optional gate undefined is
ambiguous. Thrown values are not inspected. No full collider/vehicle/train pools,
raw mutable references, or forced missing ground are captured. The existing full
dynamic/mercenary exporters retain their strict requirements.

## Reproducible profile and execution

The final copied delivery's RECEIPT identifies the reviewed profile, its canonical
PLAN hash, all producer/test/result bytes and original/instrumented responses.
The earlier `outputs/artist22_unpaused_profile_v1` is preparation history, not the
final GO target. CLI preparation performs no HTTP/browser/server operation:

```text
node tools/godot/capture_npc_unpaused.mjs --out outputs/NEW_PROFILE_DIRECTORY
```

Root reviews the final PLAN, stops the single native game during its own scheduled
window, independently confirms lifecycle, and supplies schema
`mafiozi.root-capture-go/v2` with its thread ID, exact canonical plan SHA, actual
native PID/build receipt/stop timestamp, <=180-second expiry and explicit source
monitor start policy. No GO file is fabricated or implied by this handoff.

```text
node tools/godot/capture_npc_unpaused.mjs --plan FINAL_PROFILE/PLAN.json --root-go ROOT_OWNED_GO.json --out outputs/NEW_CAPTURE_RUN_DIRECTORY
```

Execution records RUN.json, original HTTP/fulfilled-byte receipts, sealed
OBSERVED_SCALARS.json and OBSERVED_ROSTER.json, errors and cleanup receipts.
Response receipts prove fetched/fulfilled bytes, not independent executed-script
attestation. The roster binding is reviewed host metadata, not source auth.
OBSERVED roster means only the explicitly named pre-queue observation scope.
Native registration/admission stays false even when the roster is observed.

The runner may stop after a closed registration without any natural getter;
absence is not repaired by calling it. Poll latency can allow post-registration
events to fill the buffer; that yields HOLD. No auto-seal is inserted into source.
Parent exits never prove all browser descendants exited; root_restore_allowed
always remains false until Root's separate process inventory and restore step.

## Validation and cost

Author collector: 99 CPU checks. Transformer: 70 actual-source semantic checks.
Reader: 41 checks, including malformed registration end order and exact numbers.
Independent actual-source collector/transform/reader integration: 92 checks.
Independent runner guards: 51 checks. Results and final script hashes are included in the delivery; their
recorded limits take precedence over any abbreviated counts here.

Collector-only fixed CPU fixtures used 20 warmups and 60 alternating paired
samples. At 1,024 events recording p50/p95 was .0430/.1139 ms; at 8,192 events
.3721/.4291 ms. Corresponding no-op fixtures were .0064/.0232 and .0464/.0707 ms.
Later snapshot allocation was 4.607/9.879 and 42.833/60.405 ms respectively.
Default allocation: 2,064,640 typed-array bytes, 229,440 primitive-reference slots
and a 1,048,576 UTF16-unit aggregate string limit. Runtime/GC/process RSS and full
scene FPS are not measured by these numbers. Actual transformed-source fixtures
(20 warmup/40 alternating pairs, same source read counts/results, no overflow)
are in OBSERVER_COST.json. Original→observed p50/p95 ms: getter rows
1.1128/1.6986→1.7336/2.1615; support cache .2362/.2643→.5568/.6084; logical
contact .5879/.7902→1.3635/1.7620. This is measurable diagnostic overhead,
not a cost-free observer or acceptance for continued use in gameplay.
No production observer installation is proposed.

The original placement deadlines remain 4/2 ms. Instrumentation changes timing
and stack shape, so CPU parity cannot establish identical slice membership or
pristine uninterrupted gameplay. Snapshot overhead remains relevant even outside
the source stack. Source/GPU capture, complete workload/memory qualification,
Windows Chrome cleanup and gameplay/FPS acceptance await Root's explicit window.
No function from this package has been added to the active native game.
