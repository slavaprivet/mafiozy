Receipt JSON must repeat the run metadata, status and evidence, plus started_at,
completed_at and exit_code=0. Empty objects/arrays, unresolved placeholders, wrong
scene/population, hash drift, missing evidence and missing receipts are rejected.

structurally valid and explicitly reports no runtime acceptance.

Passing this checker establishes only completeness and consistency. It does not
prove that a receipt is authentic, that Godot ran, that a visual result is correct,
or that the whole game is accepted. QA must inspect real runtime evidence.
