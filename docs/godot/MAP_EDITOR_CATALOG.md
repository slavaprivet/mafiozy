# Каталог редактора карты Godot

Экспортёр: `tools/godot/export_map_editor_catalog.mjs`. Данные:
`godot/mafiozi_walk/data/map_editor/catalog.json`.

`node tools/godot/export_map_editor_catalog.mjs` обновляет только каталог.
`--check` проверяет воспроизводимость текущих исходников и ресурсов.
Тест: `node --test tools/godot/test_export_map_editor_catalog.mjs`.

## Реальное покрытие

Полный семантический inventory source карты: 75 зданий, 3 изолятора,
164 авторских объекта декора и 9 659 объектов процедурных планов — 9 901 ID.
196 уникальных SHA оригинальных GLB всех LOD каталога, без копирования моделей.
В текущем Godot-проекте обнаружены только 5 идентичных ресурсов этой карты;
16 авторских объектов присутствуют в исходном `block.json`. Это не означает,
что вся карта загружена или что редактор этих объектов интегрирован в LIVE.

Схема `mafiozi.godot.map-editor-catalog/v1`:

- `resources`: `id`=SHA, оригинальные `sourcePaths`, размер, исходные количества
  материалов/мешей, `resPath` только при совпадении полных байтов в проекте.
- `assets`: все элементы обоих исходных каталогов, LOD/bindings и дополнительные
  bank-shell assets текущей карты; статус native ресурса отделён от допуска palette.
- `objects`: стабильный `key`=`dataset:id`, неизменённый source `id`, оригинальные
  metadata авторских объектов в `sourceRecord`, `transform`, `resourceId`,
  `positionLocalM`. Геометрия/коллизии/специальные carOnly-флаги не упрощаются.
- `generatedCollections`: зависимости процедурных групп и честный статус
  `pending-native-generator`. `generatedPlans` содержит полные оригинальные
  записи всех рассчитанных source objects и railway points, поскольку
  семантические summary отдельных объектов намеренно компактны. Повторные
  runtime navigation/traffic/collider индексы не экспортируются: только
  laneGraph/trafficPlan добавили бы 47 МБ ненужных данных. Они пересобираются
  соответствующим владельцем из hashed source planners, а не теряются в save.
- `surface.sourceDocument`: весь исходный grid/masks/protected/police/bridge;
  `authoredExtras` сохраняет покрытия, материалы и unresolved.
- `sources`: SHA/размер всех входных JSON и основных планировщиков.

## Координаты и безопасность

Правосторонняя система, Y вверх. Source `positionM` уже в метрах: local = source
минус `originM` из текущего block. Дополнительно умножать на 4.1 нельзя.
Только c/r клеток переводятся в source X/Z через 4.1 м. Yaw сохраняется,
`modelLocalOffsetM`, horizontal/uniform scale остаются оригинальными.

`available` означает только наличие оригинального GLB в проекте, не разрешение
изменять gameplay. `editCapability` требует регистрации host и пересборки
зависимостей. Игровая authority не активируется экспортёром; gameplayActive=false,
исходное значение отдельно сохраняется. Составные здания с дверьми/интерьерами,
светофоры, парковки и железная дорога требуют собственных native adapters.

## Производительность

Каталог загружать лениво при первом K, а не при старте игры. Не создавать
9 901 Node/Mesh на основе inventory. Source массивы предназначены для индексирования
и выбора, не для frame-loop. PackedScene/mesh/material кешируются по resource SHA;
нативный imported ресурс нельзя копировать на каждый объект. Размер манифеста
выше компактного LIVE-кропа, потому что он lossless сохраняет планы и маски.
Экспортёр не меняет текстуры, материалы, LOD, тени и геометрию.

CPU/Node тесты не заменяют GPU/LIVE приёмку. Полный native генератор, фактическое
редактирование всех объектов и производительность всей карты пока не проверены.

## Приём оригинальных GLB

`node tools/godot/install_map_editor_assets.mjs --check` — read-only проверка
всего набора; без параметров тот же dry run. `--install` явно разрешает
byte-identical staging в `outputs/map_editor_asset_stage/<SHA>.glb`; `--limit 3`
ограничивает объём одного пакета. Перед первой записью проверяется полный набор
источников. Изменённый целевой файл не перезаписывается. External textures/buffers
блокируют импорт до отдельного полного приёма ресурсов, а не выбрасываются.
Существующие идентичные GLB повторно не копируются. Скрипт не меняет каталог,
главную сцену и параметры Godot и не запускает GPU/import. Staging находится
вне `res://`, чтобы editor auto-scan не импортировал незавершённый пакет.
Приём в `res://assets/map_editor/<SHA>.glb` выполняет Координатор21 только после
проверки пакета; затем каталог обновляется отдельно его экспортёром.

Проверенный первый пакет до введения freeze: 3 byte-identical GLB уже скопированы
в project assets; они не запускались в LIVE. Остальные project writes остановлены.
Полный набор GLB: 196 уникальных ресурсов, 30 212 460 байт. В каталог после первого
пакета входит 8 имеющихся в project оригинальных ресурсов вместо прежних 5.
