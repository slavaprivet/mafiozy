# Художник22: физическое падение NPC, 30 сентября 2026

Пользователь требует физического падения при окончательной смерти, удара машиной с учётом скорости/массы и проезда колёсами без застревания. Из этого пакета **физическая презентация окончательной смерти проверена в Godot**, а контакт/HP/игровой переезд ещё не приняты. Одна игровая сцена, экспорт, source HP/authority и LIVE принадлежат Координатору22. Git и GPU Художник22 не трогал.
