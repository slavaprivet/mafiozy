# Provenance and rights gate

The source package declares `civic_park_decor_kit_v2.blend` as its source and
contains no image textures, external runtime URIs, stock-asset references, or
third-party licence files. The independent audit pinned the source Blend file,
all 57 GLBs, and all three proof renders by byte size and SHA-256.

That technical evidence is sufficient for internal project staging, but the
source package does **not** contain an explicit authorship statement or public
redistribution grant. This package therefore records:

- allowed scope: `internal_project_staging_only`;
- public redistribution cleared: `false`;
- fail closed outside the allowed scope: `true`.

This is deliberately not upgraded to a stronger rights claim by inference.
Before a public release, add an explicit rights/provenance declaration from the
asset author and update the pinned registry through a separately reviewed gate.

The catalog proof layout carries no placement authority. Only the explicit
candidate anchors in `placement.candidate.v1.json` may be considered, and they
still require live runtime preflight and coordinator approval.
