# Actual terrain, water and physical floor owner receipt (checkpoint candidate)

`terrain_owner.gd` supplies only the `terrain` callback of `ordinary_building_tx.gd`. It binds the frozen Coordinator22 actual `main.gd`, `block.json`, and native water JSON by SHA, the live `main` instance, its source block, 303-cell native water host and mesh, and every dry `StaticBody3D` floor strip generated from the 31×31 source grid. The receipt snapshots node, shape and mesh identities plus physical dimensions, transforms, filters, water summary and source surface. `verify()` rejects lifetime, pause, resource, and scene drift. `commit()` rejects changed height, outside-crop placement and overlap between moved source collision polygons and water cells. It changes no terrain state; `rollback()` verifies and releases its lease.

Stage with `node tools/godot/map_editor_terrain_owner_candidate/stage_checkpoint.mjs --stage`. This creates a new outputs-only project using the pinned ordinary-building stage and adds the owner plus native fixture. Run a sequential Godot import and `--headless --path <stage> --script res://test_terrain_owner.gd`. The fixture uses the real terrain receipt, exact native townhouse root and two sibling colliders, but synthetic `pause`, `navigation` and `traffic` tokens. It checks accepted dry move, actual water/vertical/outside-crop rollback, downstream failure rollback, floor and water resource mutation refusal, and undo. No production/main edit or GPU process is involved.

Verified on Godot 4.7.2 headless in `outputs/map-editor-ordinary-building-tx-BvHjuT`: sequential import had no script/engine diagnostics; native fixture exited 0 with 21/21 checks and no errors. The exact staged owner SHA-256 is `c87aafe2edef278bd4d5ea4e0164ec8c2948010629f22477a36fcb7fcf4be4b5`.

This is a checkpoint admission only. The working main has changed; a new source pin and full loaded-scene review are required before adoption. The terrain receipt does not own navigation baking, traffic occupancy, actor relocation, save/export, or full support on sloped terrain. Current checkpoint ground is level; edits that change vertical placement fail closed. Headless Godot returned identity for MultiMesh instance transforms, so the receipt pins each terrain MultiMesh resource, buffer, instance count, material and SHA-pinned source builder, but cannot independently validate each GPU instance placement in this fixture. Other owner receipts remain mandatory, and this file must not be used as evidence that native map editing is ready.
