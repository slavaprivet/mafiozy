# Source-exact native procedural geometry candidate

Frozen code-only review candidate; **not production integration**. This folder is outside the Godot game project and does not trigger its importer. No static replacement primitives, reduced LOD or color/material simplification.

Use `node tools/godot/export_map_editor_procedural.mjs` to reproduce original verified source buffers in `outputs/map_editor_procedural_source`. Then `node tools/godot/map_editor_procedural_native/stage.mjs --check` verifies fixed manifest SHA, every dependency, source catalog and 982 binary buffers without writes. `--stage` creates `outputs/map_editor_procedural_review` (or `--target` another distinct outputs subdirectory), generates nine original Three LOD oracle states, and copies frozen code/resources once. Existing mismatched files are refused, never overwritten. The fixed reviewed source SHA is intentional: changed source dependencies require a new reviewed candidate, not silent hash relaxation.

Owner can run native Godot `--headless --path outputs/map_editor_procedural_review --script tests/test_procedural_factory.gd` and separately `tests/test_roads_factory.gd`. Optional `test_emission_transfer.gd` needs the verified original SHA GLB in the sibling `outputs/map_editor_asset_stage`.

Verified: **448,582 exploration checks + 134,894 road checks + one native GLTF emission oracle**, zero failures. Actual native Mesh geometry positions/UV/source normal inputs/index winding, CPU MultiMesh upload inputs, exact source object IDs, shared resources, material importer color transfer, shadow flags and edit/undo resource identities are covered. 2,440 exploration IDs + 505 controls + 6,449 markings = 9,394 source IDs. 28,718 exploration parts/464 bulk uploads, 3,571 equipment parts/eight bulk uploads, 38,694 paint vertices/59 chunks. This is submission-count evidence, not FPS improvement.

Configure validates all bytes against the admitted manifest. Build exploration before roads when using both. Root origin conversion is applied once; original Float32 matrices/colors stay unchanged. Road edit/undo/redo requires a fresh trusted owner Callable with commit and rollback; flags or source records cannot authorize traffic/navigation mutation. Paint transforms remain upright and rebuild only their dirty chunk, touching six mapped source vertices. Failures roll back exact original Mesh identity and owner transaction.

Original exploration source LOD 64/180/hysteresis8 and range360 are retained. **Remaining gates:** original road bucket-range culling and runtime signal phase, actual GPU normal/color/material/depth-bias parity, colliders/navigation/traffic authority, UI integration and comparable full-scene p50/p95. Roads currently conservatively retain original geometry rather than culling it; original source bucket receipts remain in the manifest. Godot headless Dummy does not retain readable MultiMesh storage, so tests prove exact submitted CPU inputs, not GPU readback. Native normal codec normalizes nonunit source normals and octpacks their direction (maximum normalized direction error 0.0001294055); original input bytes remain exact. No unqualified visual-lossless/full-world completion claim is made.

MultiMesh 3D bulk buffer uses original matrices transposed into Godot row-major 12 floats plus linear RGBA4 when present; see [official RenderingServer buffer contract](https://docs.godotengine.org/en/latest/classes/class_renderingserver.html#class-renderingserver-method-multimesh-set-buffer).
