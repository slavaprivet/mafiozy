# Six protected special buildings — owner transaction candidate

`special_building_tx.gd` is a source-only executable GDScript **contract**, not an admission of the six buildings into the current editor. The SHA-pinned catalog contains three bank shells and three district detention buildings, but the actual 31×31 native checkpoint contains none. The existing exact protected-record document/import guard remains unchanged. This candidate never reclassifies these IDs as ordinary/editable and never directly moves an isolated visual node.

The full-world owner must expose `map_editor_resolve_special_building(id, catalog_sha)` and `map_editor_prepare_special_edit(id, catalog_sha, action, payload, previous_receipt)`. The first returns a revisioned receipt with the exact source ID, catalog SHA, 64-hex graph seal, and true claims for visual, all collisions, interior, entrance, navigation, traffic, source ID and undo. The second returns a reversible token with `verify()`, `commit()` and `rollback()`. Commit must atomically update the **whole** native group and all gameplay owners while the tree is paused; undo must restore the earlier group. Incomplete commit/rollback is a HOLD, never silently accepted. Owner also needs to implement the corresponding six-ID document/import admission and save/reload receipt under the protected exact guard; this candidate does not do that.

The banks have authored room/vault/door and shell-envelope records. District detention sites additionally have compact aprons, physical doors, hollowing and floors, vehicle-only collision bodies, entry corridor, stop footprint and stop lane. Their original catalog `resPath` is empty; the full asset importer must resolve the canonical GLBs before owner admission. Moving only the root would break these contracts.

`node tools/godot/map_editor_special_building_tx_candidate/test_source_scope.mjs` checks six exact IDs, roles, absence from the current crop and explicit owner seams. This is source/static evidence only: no Godot fixture, LIVE performance, import/export, or visual proof. Do not install into main until root23 supplies the full-world owner API, headless window and a new protected-baseline acceptance path.
