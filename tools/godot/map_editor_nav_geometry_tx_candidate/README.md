# Ordinary building navigation geometry receipt — tools only

The native inspector uses the Coordinator22 immutable actual-main checkpoint with three source residents. It reads the original navigation host's captured collision triangle stream and reconstructs it from every current direct-main and Printshop static collider. Exact equality is mandatory before it proposes a move, yaw rotation, delete, undo or redo restoration. It delegates source admission to the pinned `ordinary_building_tx.gd` inventory: seven ordinary buildings with 16 native collision siblings are supported, including townhouses `...-012` and `...-013`, gun shop and pawnshop. Each proposal changes only that building's exact sibling set; source IDs, shape resources, every other static collider, and all three resident IDs are preserved. Undo/redo receives the original transaction's root/body snapshot and verifies node, shape, parent, collision state, finite frame and shared yaw/translation affine before proposing the restored collision stream. The inspector itself never mutates the scene or mints a lease.

`shadow_navigation_owner.gd` is a concrete two-map owner protocol. It submits the proposed collision stream to an isolated native NavigationServer backend while the real resident, policy, queue and navigation pause leases remain active and the scene tree stays paused. Every READY poll verifies that original lease and source geometry. It returns READY only after async bake, map/region iteration, source lineage, and empty job ledgers agree. The root transaction then changes exactly the building root and sibling colliders, finalizes those leases while paused, briefly unpauses to flush them, and restores root pause in the same call stack before the next physics tick. The owner swaps in the READY shadow map only if the *current* colliders equal the proposed stream. It retains the old native map and exact geometry/version counters for reverse rollback after the scene is restored. Failure is HOLD; no stale backend callback is replayed into a changed map. Old map disposal is delayed until a post-resume final receipt. Godot's async bake and map iteration did reach READY while the tree stayed paused in the native fixture below.

This API does **not** yet provide the `navigation` token required by the original `ordinary_building_tx.gd`. That transaction commits all four owner tokens before resident lease release, while safe map swap needs a separate post-release root-paused phase. A root coordinator must split scene prepare/commit from publication and compose terrain/traffic plus the population atomic lease. `nav_geometry_receipt.gd.acquire_owner_lease` therefore still refuses `NO_ATOMIC_NAV_PUBLISH_AND_READY_RECEIPT_UNDER_EDITOR_PAUSE`; this is a correct closed production gate, not a synthetic success. Printshop, protected bank/detention sources, 67 buildings absent from actual main, unknown IDs, active static batching, stale source inventory, unexpected collider shapes, and altered resident/nav ownership are refused by the pinned source and geometry checks.
