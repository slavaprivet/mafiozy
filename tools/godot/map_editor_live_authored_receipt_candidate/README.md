# Actual-main authored live-root audit, source-only / native unrun

`live_authored_owner.gd` is a tools-only owner adapter for the immutable Coordinator22 checkpoint `main.gd` SHA `faac9219...` and `block.json` SHA `1523f52e...`. It accepts no caller root map. It scans direct source-owned roots of the *actual main* and checks all 16 IDs, model/path SHA, catalog transforms, and unique roots. For 15 ordinary building/decor roots, it compares the live imported scene tree to an independent instantiation of main's pinned PackedScene, including mesh resource and active material identities, while refusing static render batching. It snapshots root lifetime/transforms, scene identity, and source SHA for later verification. This remains an unrun candidate, not native or LIVE proof.

Printshop is a deliberate special-case HOLD. Its native interior adapter modifies the original visual's meshes, creates new geometry and moves doors; comparing it to the raw source GLB would be incorrect. A separate Printshop-owned receipt must attest its pinned interior package, modified mesh/material generation, door state/lifetime and base-source restoration before the main owner may issue a 16/16 borrowed-root receipt. `verified_roots()` therefore returns no partial approved map. The authored builder's `borrow_live=true` fails closed on this HOLD; `borrow_live=false` can still exercise the isolated all-242 visual fixture. No object is authorized for edit, save, collision or gameplay by this adapter.

Node source mapping check: `node tools/godot/map_editor_live_authored_receipt_candidate/test_source_mapping.mjs` — 16 exact catalog ID/model/source file/transform mappings; 15 ordinary, 1 Printshop HOLD. It does not execute Godot, instantiate a scene, or validate runtime mesh/material parity. Any future native test must use a Coordinator22 CPU window and inspect import/engine diagnostics. The static batching owner needs its own source-ID-to-render-root receipt; this adapter rejects that mode.
