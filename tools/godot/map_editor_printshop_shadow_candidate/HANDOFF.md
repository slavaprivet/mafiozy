# Original printshop CPU-shadow constructor candidate

Output-only, not installed into production or the frozen placement candidate. Run `node tools/godot/map_editor_printshop_shadow_candidate/stage.mjs`; Godot 4.7.2 `--headless --path <absolute outputs/map_editor_printshop_shadow_candidate> --script test_printshop_shadow.gd`.

`printshop_shadow.gd` constructs the actual 15 source MultiMeshes/280 instances/215 linear colors. Exact original `_mesh`, `_matrix`, `_linear_color` functions build resources and submission values; no geometry/color approximation or per-instance nodes. Input must equal the trusted SHA-pinned actual source descriptor, not merely share its ID/asset hash. Instance transforms/colors are recorded by the same constructor/write path that submits native values. This proves CPU submissions only, never native headless storage or visual parity.

APIs: `build(source)`; `initial_snapshot()`/`shadow()` detached copies; `batch_nodes()` original MultiMesh nodes; `generation()`; `guard()`; `write_transform(index,slot,frame)`, `write_color(index,slot,color)`, `write_instances(index,{slot:{transform?,color?}})`; `set_visible_count`, `set_batch_frame`, `set_bounds`; `request_owner_receipt(actualOwner,boundSeal,boundValidate)`; `owner_receipt_valid`; `dispose`.

Descriptor indices are stable keys because names repeat. Source-count/format/color/customdata flags are fixed. Raw buffer/RID writes, resize, mesh/material replacement and customdata writes are deliberately **not supported**; a caller needing these must invalidate/rebuild through the actual source owner rather than bypass the shadow. No script/data flag grants approval. A future trusted actual owner seal callback returns an opaque RefCounted receipt, and its validator must return that same receipt for this builder/epoch; both callbacks must be bound to that owner. Test fixture receipt acceptance is not a genuine sealed production lifecycle or editor scene admission.

Each successful managed mutation bumps generation and clears the owner receipt. Validation is atomic before batch writes. The private initial snapshot and source are recursively frozen; public snapshots cannot alias them. Weak native/mesh/material identity guards and unique resource watchers reject lifetime/replacement/changed events; exact finish uniforms catch silent shader parameter changes. Detected unknown changes poison the generation even after restoration. Watchers disconnect before owned nodes/resources are freed. Returned native nodes remain exposed mutable resources: an unobserved direct setter followed by restoration cannot be disproven. Hence source owner routing/no-RID/no-reload sealed lifecycle remains mandatory, not asserted by this builder.

The two source internal-door batches (35/36) can mutate through managed instance methods; this supplies a building block for their original animation, not migrated door mechanics. Service-pivot batches (37/38) preserve source parent-motion metadata; host must attach them to the actual service pivot and guard its phase. This package does not construct doors/colliders/nav/service authority. Nodes are initially owned by the unpublished factory; dispose releases factory children. If a genuine host reparents nodes, that host owns their lifetime and must retire them explicitly; no scene installation is performed here.

Remaining gates: genuine actual owner sealed writer/lifecycle receipt; all external writers and resource aliases audited; source/script lifecycle no-reload lease; complete actual parent/door/collider/nav/gameplay transaction; coordinated live renderer/parity/performance. CPU tests are not full-scene FPS acceptance.
