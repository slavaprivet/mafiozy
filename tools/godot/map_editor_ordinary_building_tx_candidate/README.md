# Ordinary native building transaction — tools-only candidate, not admitted

`ordinary_building_tx.gd` is executable native scene mutation code for the **seven ordinary live buildings** in the immutable Coordinator22 checkpoint. It selects by exact source ID from SHA-pinned actual `main.gd`, `block.json` and frozen 75-building catalog, then uses the existing read-only native inventory to capture the original visual root and **all 16 direct-main sibling collision bodies** across those seven. One selected root plus its exact sibling set is the transaction unit. Printshop, three bank shells, three detention records and the 67 buildings absent from actual main remain HOLD. Active static batching is refused.

`move`, `rotate`, `delete`, `undo`, and `redo` share one owner transaction. Move/rotate apply one affine delta to the root and each detached sibling exactly once; imported meshes, materials and collision shape resources are not replaced. Delete retains the source nodes, hides the root, zeros sibling collision filters and disables its shapes. Every operation snapshots root/body frames, parent/lifetime, visibility, filters and shape-disabled state. Undo restores the exact prior snapshot; redo restores the exact post-operation snapshot, and a new edit invalidates the redo branch. An owner-commit failure attempts exact scene plus downstream rollback, and an incomplete rollback enters terminal `HOLD_ROLLBACK_INCOMPLETE` instead of reporting success. Source identity and inventory fingerprint are checked before every mutation. No real save/export path is enabled.

Four owner leases are **mandatory per operation**: `pause`, `terrain`, `navigation`, `traffic`. Each callback must return a RefCounted token with `verify`, `commit`, and `rollback`; all token calls must return `{ok:true, ready:true, pending:false}`. Missing callback, pending async publication, stale owner/participant, unpaused tree, or active static batch refuse before scene mutation. Commit must retain the paused tree through final verification. The actual checkpoint does **not** supply a general building-geometry transaction from terrain/nav/traffic, so no caller currently has genuine tokens and native editing is **NOT READY**. Caller-supplied fixture tokens cannot be treated as production owner receipts.

`test_ordinary_building_tx.gd` is an isolated native mechanics fixture. It loads the actual checkpoint main, proves missing callbacks leave the scene unchanged, then uses explicitly synthetic tokens to exercise one townhouse root plus its two real collision siblings through move/rotate/delete/undo/redo, redo branch invalidation, and a traffic-commit rollback. The full native scene fingerprint covers mesh/material/shape identities, collision filters and transforms; separate assertions preserve root and sibling source IDs. Godot 4.7.2 headless import and run passed in `outputs/map-editor-ordinary-building-tx-rjCoAE`: 32 checks, zero failures, 32 synthetic lease tokens, exit 0 and no engine errors. The first fixture run failed because it called the transaction in the physics frame; the fixture now awaits a process frame after pausing, as the contract requires. Its success proves the scene operation/rollback code, **not** genuine owner admission or gameplay correctness. `stage_checkpoint.mjs --dry-run` passed with 192 immutable checkpoint files, closure SHA `8a5f5dbf137ef3c63c2a8cb98781dd4c3354be0e9565703fb04dcb0ad82e0578`, prospective 197-file isolated stage. `test_source_scope.mjs` passed seven ordinary live IDs, 16 sibling bodies, 67 absent buildings, Printshop and six special HOLD. No GPU or loaded-city performance run was made.

`node tools/godot/map_editor_ordinary_building_tx_candidate/stage_checkpoint.mjs --stage` prepares an outputs-only project. Import and the native fixture must run sequentially, with engine logs inspected even on exit 0. This stage pins the immutable Coordinator22 actual-main checkpoint; the active working `godot/mafiozi_walk/scripts/main.gd` has since changed, so this is not acceptance against the newest live game. Do not install this into production or claim K/edit readiness from a synthetic lease. The next genuine owner package must expose paused geometry prepare/verify/commit/rollback receipts for terrain/nav/traffic, including async nav generation, support/occupancy and original source collision descriptors; only then may the transaction be wired to editor selection/history/save under Coordinator23's main ownership.
