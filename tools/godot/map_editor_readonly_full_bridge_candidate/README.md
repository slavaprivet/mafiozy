# Full-source read-only bridge: index and owner API (source-only)

This is the next integration boundary after K pause v2, **not** a working full-world renderer or editor. No second window, viewport, GPU instance, production `main.gd`, or game state was changed. `source_index.mjs` proves a complete source-addressable catalog from pinned original bytes: 9901 unique identities, 242 authored + 9394 procedural + 265 transport, and 249 **catalog anchor** cells of 64 m. The structural test passes 89,377 checks. Its `renderedIds=0` and `editorReady=false` are intentional: metadata coverage is not visual coverage or edit admission.

The prior full assembly's 9901 composite registry and paged UI are fixture-backed (`test_unified_registry.gd`, `test_full_paged_editor.gd`). They cannot be mounted into actual main with `{approved:true}`. Current actual main contains 16 visible objects (8 buildings + 8 decor); its geometry/terrain/water/transport/NPC owners are separate. The new index retains source keys, IDs, categories, exact local anchors, and manifest lineage. For records without `positionLocalM`, it derives the anchor only from the original source proxy and catalog origin, not a replacement model. It never mutates a source record or declares it editable.

**Visual spatial admission is deliberately absent.** `catalogAnchorCells` is for finding catalog records near a position, never for loading, culling, or eviction. Every record has `visualSpatialState=UNVERIFIED_SOURCE_EXTENTS` and `visualEvictionEligible=false`; `visualCellIncidence=null`, `visualEvictionEnabled=false`, and `visualKeysForCell()` throws. The railway-alignment source proxy alone spans hundreds of metres beyond its single anchor cell, while road markings are merged into batches that cross many cells. Proxies and catalog positions are not independently verified render bounds, and GLB mesh extents are not established here. A later owner must supply source-hashed, conservative render/physics batch bounds and multi-cell incidence, including batch-to-ID mapping, before spatial streaming or LRU eviction may be enabled. Until then, budget pressure must HOLD rather than silently drop visible content. The structural test explicitly rejects visual-cell lookup and eviction for the long railway and roads.

## Minimum real owner API before same-app full-world view

The actual main must expose a read-only source-world owner bound to its current scene generation and a K pause receipt. No caller-supplied boolean is an authority token. Required methods and receipts:

1. `open_readonly_world(pause_receipt, catalog_sha, procedural_sha, transport_sha) -> session_receipt`: verify current main/player/transport/nav/water lease, world-origin 4.1 m contract, exact source hashes, and runtime generation. Must not change game source state.
2. `begin_chunk(session_receipt, exact_source_keys) -> job_receipt`: no synchronous full-map build and no anchor-cell visual selection. The owner must map all requested IDs to original GLB or original procedural/transport batches, preserving transforms, materials, mesh/color arrays, collision ownership, and protected status. No placeholder boxes or filtered trees. Duplicate IDs across chunks forbidden.
3. `step_chunk(job_receipt, max_usec, max_bytes) -> {pending|complete, native_root, covered_source_keys, resource_receipts, bytes}`: resumable construction so one call cannot overrun the frame budget. Commit a completed chunk only if covered IDs equal the requested set and receipts match original resources; otherwise keep the previous visible scene and report HOLD.
4. `release_chunk(session_receipt, job_receipt)` and `close_readonly_world(session_receipt)`: release only this preview's resources, not live game nodes. Stale generation/owner must fail closed. There is no cell-based release before verified visual incidence. A read-only catalog may stay visible while a visual chunk is HOLD; the UI must say which visuals are not loaded.
5. `propose_edit` must be a **separate** transaction requiring actual gameplay/terrain/collision/nav/traffic/water/save owner receipts, exact rollback, and post-commit verification. The read-only session must expose no edit, delete, import, export, or save actions.

Budget to measure, not a performance claim: start with ≤2 ms main-thread work per frame, ≤2 cooperative steps/frame and ≤384 MiB preview resources. No off-screen LRU or ≤16-active-cell target is valid until exact visual incidence is proved. The source index is cheap; GLB imports, 464 exploration batches, merged road-paint/road-sign batches, and parking/rail batches are the expensive owners. Their frozen factory `configure/build_*` methods are presently eager, so invoking them on K would violate the budget. Split them into resumable exact-source builders before connecting `step_chunk`, with CPU p50/p95 and resident-memory comparison against original main, then root-coordinated same-window GPU frame-time/visual comparison. Do not hide a regression by omitting geometry/materials/collisions.

Exact dependencies currently missing: special-building/interior adapter for six authored records; genuine navigation quiescence and deferred bake/query generation when residents run; stable transport/traffic/collider lease; terrain and water commit/rebuild receipts; station CanvasTexture pixel capture and actual three-car train factory for 32 protected railway IDs; source-render parity for road paint/depth and railway shaders. Those 38 protected records still appear in the catalog, but neither visuals nor edits may be falsely marked ready. All source data and existing visual quality remain untouched while these owners are built.

Source-only check: `node tools/godot/map_editor_readonly_full_bridge_candidate/test_source_index.mjs`. No Godot import/headless or GPU run has been performed for this bridge.

## Resource-path and building-owner boundary (30 September)

`test_resource_boundary.mjs` is a second, read-only Node check against the frozen catalog and the isolated 196-GLB source assembly. It hashes every staged GLB against the catalog and its stage receipt. It finds 196/196 valid staged resources (30,212,460 bytes), but only 3 currently installed at the canonical `res://assets/map_editor/<SHA>.glb` path in the actual project. The frozen catalog has 3 such paths, 5 still-valid historical `res://assets/buildings`/`decor` paths, and 188 empty `resPath` values. Thus the isolated successful import is not a production installation or a catalog metadata update. Runtime resolution must use a verified SHA-to-canonical-path registry for the project actually loaded; the existing `catalog_factory.gd` already constructs that canonical path and verifies raw bytes, but it cannot load the 193 currently missing production files.

Of 75 building records, only 8 are live in actual main; 36 catalog `available` flags describe source/catalog availability, not owner registration. Every building has `editCapability=requires-host-registration`. Three bank shells plus three detention records require a trusted special-building adapter in the frozen static factory; the regular exterior-collision option deliberately does not confer that authority. The existing `preview_host_bridge.gd` scans only actual `block.json` roots and cannot register 67 absent buildings. No gameplay/edit permission follows from an isolated GLB import, a historical `resPath`, or catalog `available`.

Run: `node tools/godot/map_editor_readonly_full_bridge_candidate/test_resource_boundary.mjs`. This does not invoke Godot, copy assets, or modify production. Re-run after production source changes; a different result must be reviewed rather than silently accepted.
