# Actual preview traffic owner gate (tools only)

`traffic_owner_gate.gd` reads the live native main, the real `PreviewTransport`, its `TransportRuntime`, parked vehicle body and parking catalog. It issues a read-only receipt bound to their identity, session, clock, pending interaction, body collision filters/pose and source building ID. `verify` detects owner or participant drift. `prepare_geometry_edit` deliberately returns `traffic_geometry_transaction_owner_missing` and never returns a token, so the ordinary-building transaction cannot mistake this receipt for one of its four mandatory commit leases.

Actual ownership audit: `main.gd` builds surface collision strips and same-source building collision siblings itself. `preview_transport.gd` owns one parked native rigid body, the player seat collision exchange and the session. `transport_runtime.gd` owns parking catalog, vehicle pose, roster and seat/access transitions. None exposes a reversible transaction that republishes edited building/road geometry to parking, traffic access, support and collision users. Freezing the car or reading its pose does not supply that transaction. The existing vehicle-pause candidate is separately scoped to a stationary car and preserves its collision layer/mask; it does not make buildings editable.

This package makes no production/main edits, opens no GPU window and makes no edit-success claim. Root/transport owners must provide a reversible geometry prepare/verify/commit/rollback receipt plus affected parking/route/access/support and collision validation before this gate can return a real token. The ordinary native building transaction remains HOLD even after a genuine traffic token until its other required pause, terrain and navigation owners are ready.

Godot 4.7.2 headless parse passed. The isolated immutable Coordinator22 checkpoint was imported into `outputs/map-editor-ordinary-building-tx-WnLxB3`; `test_actual_owner.gd` passed 10/10 native checks, no engine errors. It read the actual eight-building scene and its actual preview transport, rejected a forged receipt, rejected move without a geometry token, detected body collision filter drift, and left car/player collision filters and car pose unchanged. This fixture runs against that pinned checkpoint rather than the newest shared working main. No loaded-city frame-time or GPU measurement was made because the gate admits no edit.
