# CPU-shadow V2 — review corrections, output-only

V1 remains frozen and **rejected for positive reuse**: generic Dictionary equality did not specify signed-zero/type policy, uniform equality was not byte-exact, blanket signal suppression could hide nested resource changes, and owner lifetime needed post-callback checks. V2 is a new package; no V1/root/native production files were modified.

V2 uses the reviewed `TrustedJSON.equal` against the exact SHA-pinned, native-parsed trusted descriptor. Float bits distinguish signed zero; safe exact integer/float transport equivalence follows that explicit reviewed policy. It does not normalize/round caller data or use an epsilon. Source +/-0 and tiny matrix mutations fail construction. Exact numeric Vector3/float shader uniform snapshots use `var_to_bytes`, detecting signed-zero and nearby double changes even when Material.changed emits nothing.

Unique watched resource callbacks bind their resource ID. Managed writer suppression applies ONLY to the currently written native MultiMesh ID; nested mesh/material/Shader changes poison the generation even during a managed write scope. Callback busy is separate from writer suppression. Tests invoke real native Resource.changed listeners in a controlled active suppression scope and confirm nested mesh/material poisoning; this simulates adversarial signal timing, not a claim that dummy native setters emit these signals. All main-thread managed writer APIs, build, owner admission/validation and dispose refuse worker-thread execution. Source count/format/raw buffer/RID writes remain unsupported.

After seal/validation callbacks, weak owner identity, in-tree lifecycle, pending deletion and callable binding are rechecked before accepting the same opaque receipt. Godot prevents immediate freeing of a currently called object; the adversarial test queues owner deletion inside its validator and verifies denial before receipt acceptance.

API and source-construction behavior otherwise match V1: original 15 MultiMeshes/280 instances/215 linear colors, same actual `_mesh`/`_matrix`/`_linear_color` paths; immutable initial copy, exact current CPU shadows and epoch invalidation for managed writes. Disposal disconnects unique watchers before freeing owned nodes/resources.
