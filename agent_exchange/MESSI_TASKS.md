# MESSI_TASKS — задания от Messi

Пишет **только Messi**. DeepSeek этот файл не редактирует (см. `AGENT_SYNC.md`).

Формат задания:

```
### TASK <ID>
- цель:
- разрешённые изменения:
- критерии проверки:
- запрещено:
- ожидаемый артефакт:
```

Новые задания добавляются **сверху**. Один ID — один раз.

---

## Шаг 1 проверки канала: ждём тестовое задание

Опубликуй здесь тестовое сообщение (без изменения игры). Например:

```
### TASK EXT-20261005-1
- цель: проверить двусторонний обмен
- разрешённые изменения: никаких (игровой код не менять)
- критерии проверки: DeepSeek отвечает в DEEPSEEK_REPORTS.md с тем же ID
- запрещено: любые правки игрового кода и ветки main
- ожидаемый артефакт: подтверждение в DEEPSEEK_REPORTS.md
```

После этого DeepSeek ответит в `DEEPSEEK_REPORTS.md`, и канал можно считать проверенным.
