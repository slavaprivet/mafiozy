# Development Notes

Короткая памятка для нового чата Codex по проекту "Мафиози".

## Текущий фокус

- Основная работа сейчас идет в `world.html`.
- Приоритет: открытый изометрический мир, прогулка по городу, NPC, банды, захват районов, машины, боевка, UI мира.
- `demo_isometric.html` использовать только как эталон физики/HP-бара, не менять без отдельной просьбы.

## Правила перед изменениями

- Сначала смотреть свежий коммит: `git log -1 --oneline`.
- Не ломать существующую архитектуру и не переписывать большие куски без необходимости.
- Использовать текущий стиль проекта: чистый HTML5 Canvas + JavaScript, без npm/node в игровом коде.
- Не трогать токены: `.token`, `.bot-token`.
- В грязном git-дереве не откатывать чужие изменения.
- После изменений запускать проверки, минимум:
  - `python check_world.py`
  - `python check_bot.py`
- Если изменение успешно, делать понятный commit и push, staging только нужных файлов.

## Локальное превью мира

Для интерактивного превью без Telegram-бота используется локальный helper:

```powershell
Start-Process -FilePath 'C:\Users\Слава\Desktop\Мафиози\venv\Scripts\python.exe' -ArgumentList '_preview_ws_server.py' -WorkingDirectory 'C:\Users\Слава\Desktop\Мафиози' -WindowStyle Hidden
```

Открывать в браузере:

```text
http://127.0.0.1:8080/preview/world.html?uid=1&name=Demo&api=http%3A%2F%2F127.0.0.1%3A8080&mode=pvp&gender=0&skin=0&body=1&face=0&hair=0&hat=0&has_look=1&mark_lvl=0
```

Что делает helper:

- отдает `/preview/world.html` как локальную preview-версию текущего `world.html`;
- подменяет запрос `coop_api.json` на локальный API `http://127.0.0.1:8080`;
- поднимает mock WebSocket `/world/sim`, чтобы убрать экран "Связь потеряна";
- отдает минимальные endpoints для инвентаря и лидерборда.

Это preview-песочница для быстрой проверки перемещения и визуала. Для настоящего онлайна, Telegram WebApp и туннеля нужно запускать основной бот/туннель через проектные скрипты.

## Важные архитектурные файлы

- `PROJECT_ANALYSIS.md` - подробный разбор архитектуры, зависимостей, слабых мест и предложений.
- `world_index.txt` - навигация по большому `world.html`.
- `ARCHITECTURE.md` - общая архитектура проекта, если файл присутствует в рабочей копии.
- `mafiozi_bot.py` - Telegram-бот, SQLite, WebApp-интеграция, серверные endpoints.
- `start_with_tunnel.py` - запуск бота и cloudflared-туннеля.
- `github_upload_world.py` - проектный способ публикации `world.html` через GitHub API.

## Рабочий цикл с пользователем

1. Пользователь тестирует мир в in-app browser.
2. Codex правит `world.html` точечно.
3. Codex запускает проверки.
4. Preview-страница перезагружается, пользователь сразу смотрит результат.
5. После успешной проверки Codex коммитит и пушит только свои изменения.
